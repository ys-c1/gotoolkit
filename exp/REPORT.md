# 多分辨率重建的边界暗边：成因、宽度等式与对称延拓的误差界

## 0. 实验设定（理论与代码逐项对应）

采用 Burt–Adelson 拉普拉斯金字塔的标准一维构件，二维按行、列可分离：

- 低通核 `w = (1/4, 1/2, 1/4)`，半径 `R = 1`，权值和为 1；
- **REDUCE**：卷积后隔 2 取 1
  `g[j] = ¼ f[2j−1] + ½ f[2j] + ¼ f[2j+1]`；
- **EXPAND**：偶数位 `y[2j] = g[j]`，奇数位 `y[2j+1] = (g[j]+g[j+1])/2`；
- 越界样本两种处理：`zero`（补零，不做权重重归一化）与 `sym`（半样本对称
  `f[−1]=f[0]`、`f[N]=f[N−1]`）；
- 暗边的载体是**只走高斯通道**的重建 `T_L = EXPAND^L ∘ REDUCE^L`（丢弃拉普拉斯
  残差）。完整拉普拉斯重建在两种延拓下都精确（见 §5 对照），因此暗边不是金字塔
  结构本身的缺陷，而是高斯通道反复边界延拓的累积。

记号：`G = max|f[n]−f[n−1]|`（一阶差分），`D = max|f[n+1]−2f[n]+f[n−1]|`（二阶差分）。

## 1. 命题一：暗边来自补零延拓，宽度满足等式 W_L = 2^L

### 1.1 单层机制（L=1）

对常数信号 `f[n] ≡ c`，REDUCE 的首样本需要越界样本 `f[−1]`：

```
g[0] = ¼ f[−1] + ½ f[0] + ¼ f[1]
     = ¼·0  + ½c + ¼c = 3c/4        （补零）
```

而内部样本 `g[j] = c (j≥1)`。EXPAND 回原尺度后：

```
y[0] = g[0] = 3c/4
y[1] = (g[0]+g[1])/2 = 7c/8
y[n] = c  (n≥2)
```

代码实测（`verify_1d.py`）：`g[0]=135.000000`（c=180 时即 3c/4）、
`y[0]=135`、`y[1]=157.5`、`y[2]=180`，与闭式完全一致。**误差为负（变暗）、
仅占据最外侧两个像素**——这就是一圈暗边的最小单元。

### 1.2 多层宽度等式

关键观察：REDUCE 的下标 `2j±1` 对所有域内 `j` 都不越界（最大为 `2(s−1)+1 = 2s−1 ≤ N−1`），
所以**暗边不产生于 REDUCE 的域内样本，而全部产生于 EXPAND 阶段对越界位的补零**。
EXPAND 的支撑半径为 1，每完成一次「REDUCE+EXPAND 往返」，边界污染向内部扩散的
距离翻倍：第 ℓ 层的一个污染位，在更细一层映射到偶数位 `2j` 与相邻奇数位
`2j±1`，即影响半径 ×2。

用 δ 脉冲探测显式算子矩阵 `T_L`（`bounds.py` 的 `tl_matrix`），在 8 种信号长度
× 6 个层数上穷举核验，得到严格等式：

> **左缘（上缘）暗边宽度　W_L = 2^L。**

右缘（下缘）因 `floor` 减半链 `s_{j+1}=⌊s_j/2⌋` 的末位奇偶性，宽度为
`2^L−1`（偶数尺寸链）或被奇数层的越界偶数位补偿为 `2^L`；`bounds.py` 用与算子
同构的污染下标布尔传播 `right_width()` 逐位复现，全部 `(n,L)` 组合通过。
**二维平坦场的实测（N=128，`border_widths.csv`）：**

| L | 左/上宽（实测） | 右/下宽（实测） | 理论 2^L |
|---|---|---|---|
| 1 | 2 | 1 | 2 |
| 2 | 4 | 3 | 4 |
| 3 | 8 | 7 | 8 |
| 4 | 16 | 15 | 16 |

边端的有符号偏差随层数加深（c=180，补零不重归一化）：列 0 偏差
`−45.0, −67.5, −78.75, −84.38 …`，单调趋于 `−c`，即层数越多暗边越宽、越深。
这解释了「层数越多暗边越明显」。

## 2. 命题二：对称延拓消除暗边，代价是外两列误差升到一阶差分阶

### 2.1 暗边消除

半样本对称延拓把越界样本替换为真实边界样本的镜像：`f[−1]=f[0]`、`f[N]=f[N−1]`。
对常数信号，所有延拓样本都等于 `c`，核权值和仍为 1，于是 `g[0]=c`、每一层
`EXPAND` 都恒等——`verify_1d.py` 实测 L=1…6 对称重建对常数信号
`max|误差| = 0`，二维平坦场四边暗边宽度恒为 0（`border_widths.csv`）。

### 2.2 代价：外两列的误差界（L=1，精确核系数推导）

对称延拓改变了边界两个输出位的等效核。用 δ 脉冲探测 `T_1`（`bounds.py` 第四节
留痕），最外两行的等效核为：

```
行 0:  ¾ f[0] + ¼ f[1]
行 1:  ⅜ f[0] + ¼ f[1] + ¼ f[2] + ⅛ f[3]
```

把误差写成一阶差分 `d_t = f[t]−f[t−1]` 的线性组合并取 ℓ1 系数（行和为 1，
常数项消去）：

- **列 0**：`e[0] = ¼(f[1]−f[0])`，故
  `|e[0]| ≤ ¼ G`；
- **列 1**：代入差分基后 ℓ1 系数和为 `7/8`，故
  `|e[1]| ≤ ⅞ G`。

两个界都是**精确的**（`bounds.py` 用 `Fraction` 算出 `1/4`、`7/8`，2 万次
Lipschitz 随机信号模糊测试逼近但不超过界；斜坡 `f=3n` 上列 0 误差恰为
`0.75 = G/4`，界被取到）。

代价的本质：内部像素的误差只依赖**二阶**差分（见 §3），而外两列的误差依赖
**一阶**差分——边界处理的精度阶从 `O(D)` 降到 `O(G)`。对多层 L，外两列的 ℓ1
常数随 `2^L` 放大（`bounds.py` 第二节精确分数）：

| L | 列 0 常数 C₀ | 列 1 常数 C₁ |
|---|---|---|
| 1 | 1/4 = 0.2500 | 7/8 = 0.8750 |
| 2 | 11/16 = 0.6875 | 87/64 = 1.3594 |
| 3 | 97/64 = 1.5156 | 1057/512 = 2.0645 |
| 4 | 803/256 = 3.1367 | 14475/4096 = 3.5339 |

即多层时 `|e[0]| ≤ C₀(L)·G`、`|e[1]| ≤ C₁(L)·G`，全部经模糊测试验证。

### 2.3 一个必须澄清的事实

「代价是边界两列误差上升」指的是**误差界的正则性阶**从二阶降为一阶，**不是**
绝对误差比补零更差。本实验图像上（`edge_two_columns.csv`，图像 G≈3.76）：

| L | 补零 列0 max\|e\| | 对称 列0 max\|e\| | 对称理论界 C₀G |
|---|---|---|---|
| 1 | 144.77 | 0.48 | 0.94 |
| 3 | 215.39 | 2.54 | 5.71 |
| 4 | 224.15 | 3.69 | 11.81 |

对称延拓外两列的**实际绝对误差比补零小约两个数量级**——补零的暗边是 O(c) 的
系统性偏差，而对称延拓只剩 O(G) 的局部偏差。

## 3. 内部像素误差：两种延拓完全相同，边界效应不是全局变差

δ 探测表明，距边界 ≥2 个像素的输出位，其等效核完全落在域内，与延拓方式无关。
L=1 时内部等效核为偶位 `(¼,½,¼)`、奇位 `(⅛,¼,¼,¼,⅛)`，写成二阶差分基后的
ℓ1 系数最大为 `3/4`，故严格界：

> **内部像素（排除 2^L 边界带）　|e| ≤ ¾ D。**

实测高斯包络信号内部误差 0.2740 ≤ 3D/4=0.2773。多层内部 ℓ1 常数（`bounds.py`
第三节，已排除 2^L 边界影响带、线性项残余为 0）：

| L | 内部 ℓ1 常数区间 | 模糊测试实测(D=1) |
|---|---|---|
| 1 | [0.25, 0.75] | 0.74 |
| 2 | [1.25, 3.25] | 2.89 |
| 3 | [5.25, 13.25] | 9.93 |
| 4 | [21.25, 53.25] | 28.55 |

二维真实图像上（`region_errors.csv`），**两种延拓每个层数的内部误差逐位相等**
（如 L=3 内部 max|e| 均为 9.022、均值均为 1.594）。这严格证明：切换延拓只改变
宽度 `2^L` 的边界带，内部像素分毫不差，边界效应没有被转嫁成全局误差。

## 5. 对照：完整拉普拉斯重建精确，与延拓方式无关

分析与合成使用同一算子、同一延拓时，拉普拉斯残差恰好补偿高斯通道的全部误差，
两种延拓都精确重建（`laplacian_exact.csv`）：补零最大误差 ≤ 5.7e−14（浮点舍入），
对称延拓为 0.0。暗边只在「丢弃残差、只保留高斯低通分量」时出现。
