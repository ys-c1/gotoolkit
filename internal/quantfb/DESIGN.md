# 量化器 × 二阶反馈的联合设计

本包是题面「A 组现成扩散核低频偏多 → B 组只调系数收效甚微 →
量化器与反馈必须一起设计」的完整、可复算实现。所有实测数字由
`cmd/quantreport` 用 Go 实算，落在 `artifacts/quantfb/`。

- 原核底稿（**保留勿删**）：`kernel.go` 的 `OriginalFloydSteinberg()`，
  即 `7 3 5 1 /16`，测试 `TestOriginalKernelPreserved` 锁值。
- A 组：Floyd–Steinberg 原核 + 8 级 palette（步长 37，最大半格误差 `D0=18.5`）。
- B 组：只把反馈系数换成常见二阶核 `(c1,c2)=(−2,+1)`，仍用 q=37，不联调步长。
- C 组：本文的联合不动点。

## 1. 回路（阶数 2，两个系数逐项列）

逐行处理、行首两个延迟误差清零：

```
u_n = x_n + c1·e_{n−1} + c2·e_{n−2}
ỹ_n = q·round(u_n/q)          // 回路内部不夹取 ⇒ |e_n| ≤ q/2
e_n = ỹ_n − u_n
y_n = clamp(ỹ_n, 0, 255)      // 只在交付 8-bit 像素时夹取
```

噪声传递函数 `NTF(z)=1+c1 z⁻¹+c2 z⁻²`，输出误差（未夹取）是
量化误差经 NTF 的滤波。

## 2. 固定量化步长 q，解两个反馈系数

「低频」取角频率带 `|ω|≤ωc=π/4`（DFT 前 1/8 频带）。假设量化误差近似白噪声，
最小化 NTF 在该带内的能量，并强制 DC 置零 `1+c1+c2=0`（低频抑制的关键约束）。
令 `c1=−(1+t), c2=t`，则 `NTF=(1−z⁻¹)(1−t z⁻¹)`，

```
J(t)=∫_0^ωc 2(1−cosω)(1+t²−2t cosω) dω
t*  = [sinωc − ωc/2 − sin2ωc/4] / [ωc − sinωc]
    = [4sinωc − 2ωc − sin2ωc] / [4(ωc − sinωc)]
```

代入 `ωc=π/4`：

| 系数 | 精确表达式 | 数值 |
|---|---|---:|
| 第二零点 `t*` | 上式 | `0.8226665268767702` |
| **`c1`（一阶延迟 e_{n−1}）** | `−(1+t*)` | **`−1.8226665269`** |
| **`c2`（二阶延迟 e_{n−2}）** | `+t*` | **`+0.8226665269`** |

校验 `1+c1+c2≈1.1e-16`、`‖c‖₁=2.6453330538`。

> **另一种常见口径**：不强制 DC 置零、直接对带能二次型解法方程，会得到
> `(h1,h2)=(−1.7270560686,+0.9182769851)`（`UnconstrainedCoeffs`），
> 其 DC 增益约 0.191；但在 ωc=π/4 下它的 `‖h‖₁` 与上面的 DC 置零解
> **精确相同**（差 ~4e-16），所以 `q*=10` 与误差界 `18.2267` 对两组系数都成立。
> 本文选 DC 置零解，因为它在纯渐变上的实测行低频更低，且零点解释最干净。

误差预算 `(1+‖c‖₁)q/2 ≤ D0=18.5` 与稳健上限 `‖c‖₁≤3` 给出可行半径
`Acap(q)=min(3, 2D0/q−1)`。不动点附近 `2.6453 < Acap`，故无约束谱最优解可行；
预算收紧时最优解落在 DC 零射线 `t=(Acap−1)/2`（`design.go` 已实现并测试）。

## 3. 固定系数，解量化步长

要求新方案的最坏输出误差不超过 A 组量化器的最大误差 `D0=18.5`
（这就是“量化误差不许上升”的最坏情况口径），取满足该预算的最大步长
（码本最省）：

```
Δ(c) = 2D0 / (1+|c1|+|c2|)，整数 q = ⌊Δ(c)⌋
```

## 4. 交替迭代到两个解都不再变化

从 B 组系数 `(−2,+1)` 代入步长方程得初始可行整数步长 `q0=⌊37/4⌋=9`，
随后严格按「固定 q 解系数 → 固定系数解 q」交替（Go 实算轨迹）：

| 轮 | q | Acap | c1 | c2 | ‖c‖₁ | 界 B | 解出 q′ |
|---:|---:|---:|---:|---:|---:|---:|---:|
| 0 | 9  | 3.0 | −1.822666527 | +0.822666527 | 2.645333 | 16.4040 | 10 |
| 1 | 10 | 2.7 | −1.822666527 | +0.822666527 | 2.645333 | 18.2267 | 10 |

第 2 轮 q 与系数都不再变化，整数不动点为

```
(q*, c1*, c2*) = (10, −1.8226665269, +0.8226665269)，B*=18.226665 ≤ 18.5。
```

连续（不取整）不动点更精巧：`Δ*=10.1499642020…`，此时
`Acap(Δ*)=2.6453330538` 恰好切于无约束谱最优点的范数 `L1*`——
谱最优性与误差预算在同一处闭合。不同初值 `q0∈{1,5,9,10}` 都收敛到同一主不动点
（`TestAlternationFixedPoint`）。

## 5. 输出误差有界的证明（两行）

```
因 |e_n|=|q·round(u_n/q)−u_n|≤q/2，且 d̃_n=ỹ_n−x_n=e_n+c1e_{n−1}+c2e_{n−2}，
故 |d_n|≤|d̃_n|≤(1+|c1|+|c2|)q/2=18.2267（灰阶）；clamp 是到 [0,255] 的投影，对 x_n∈[0,255] 不增大误差。
```

边界初值取 `e_{−1}=e_{−2}=0`。该界不依赖稳定性假设，只用到三个有界误差的
有限线性组合；全图逐像素实测 `max|d|=18 ≤ 18.2267`（测试在 5 张片上核对）。

## 6. 实测效果（chart 256×128，详见 artifacts/quantfb/report.md）

| 方案 | 低频占比 ρ(π/4) | 低频 RMS | 量化 RMSE / max\|e\| | 输出 RMSE / max\|d\| |
|---|---:|---:|---:|---:|
| A FS 原核 q37/8 级 | 0.0785 | 4.04 | 12.23 / 18.50 | 14.33 / 35 |
| B (−2,+1) q37 | 0.0035* | 1.54（gamma 上 4.48>A 的 4.03） | 10.63 / 18.00 | 26.01 / 72 |
| **C 联合 q10** | **0.0040（比 A 降 19.8×，−94.9%）** | **0.41** | **2.90 / 5.00** | **6.47 / 18** |

\* B 的低频**占比**在纹理片上被其巨大高频总功率稀释；用绝对低频 RMS 与
gamma 试片可看出其低频并未真正压下去，且峰值/总误差严重恶化——
正是题面“调了调系数、低频没降多少”。在 gamma 渐变上 A→C 的 ρ 也有 5.8× 下降。

量化误差在 RMSE（−76%）与最大值（18.5→5）两个口径下都**不升反降**。

## 7. 复现与文件

```bash
go test ./internal/quantfb/      # 系数/不动点/误差界/恒等式/指标回归
go run ./cmd/quantreport         # 重新生成 artifacts/quantfb/ 下全部产物
```

- `kernel.go`：A 组 FS 原核（底稿）、B 组系数、预算常量。
- `design.go`：闭式系数解、步长解、交替迭代与连续不动点。
- `quant.go`：二阶反馈回路与 FS 参照实现。
- `metric.go`：行 DFT 低频占比（Parseval 口径）、绝对低频 RMS、盒式低通、统计。
- `gray.go`：冻结的确定性试片。
- `cmd/quantreport/`：报告/JSON/CSV/PGM 生成器。
