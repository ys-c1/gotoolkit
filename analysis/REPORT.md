# 色度半抽样后彩色色边的宽度公式与重建核权衡

## 0. 模型与记号

细网格（输出像素网格，间距 1 像素）上的色度信号为 `c[n]`，抽样比为 `r`（4:2:0 即
`r=2`，每 `r` 个细像素保留一个色度样本），样本位置为 `rk`：

```
d[k] = c[rk]                         （点抽样，无前滤波）
ĉ[n] = Σ_k d[k] w_s(n − rk) / Σ_k w_s(n − rk)
```

`w_s` 是紧支撑重建核，半支撑为 `s`，即 `|u| ≥ s ⇒ w_s(u)=0`，`|u|<s ⇒ w_s(u)>0`。
分母归一化保证核在任意可达位置直流增益为 1。覆盖条件 `s > r/2`，否则存在不被任何
样本覆盖的细像素列（实验中已验证该区域边界不可测，必须排除）。

---

## 1. 最大色边宽度定理

### 1.1 定理

> 对任意紧支撑核 `w_s`（半支撑 `s`）与抽样比 `r`，点抽样-归一化重建链在一条真实
> 色度阶跃边缘两侧产生的污染带最大宽度为
>
> ```
> W_max = r + 2s          （细像素单位）
> ```
>
> 该宽度与边缘的子像素相位无关；按整数像素列计数时与该值相差不超过 1 px。

### 1.2 证明

设真实阶跃边缘位于 `e`，其两侧相邻的两个样本为

```
k_L = r·floor(e/r)   （低侧最后一个样本，值 c=0），位置 p_L = r·floor(e/r)
k_R = k_L + r        （高侧第一个样本，值 c=1），位置 p_R = p_L + r
```

重建值 `ĉ[n]` 是落入 `n` 邻域的样本值的凸组合（权重非负、和为 1）。一个细像素列 `n`
的重建值偏离真值，当且仅当它同时收到边缘**对侧**样本的非零权重。

- 低侧样本 `k_L` 的支撑区间为 `(p_L − s, p_L + s)`；
- 高侧样本 `k_R` 的支撑区间为 `(p_R − s, p_R + s)`。

任何位于两个区间并集之外的列，只能被同侧样本到达，`ĉ[n]` 取该侧常数 0 或 1，**无
污染**。因此污染列的全集恰为并集

```
B = (p_L − s, p_R + s).
```

并集两端点距离（与 `e` 在抽样格内的相位无关）：

```
W_max = (p_R + s) − (p_L − s) = (p_L + r + s) − (p_L − s) = r + 2s.   ∎
```

两点说明：

1. **为什么宽度随内容变。** 支撑决定的是几何外廓 `B`，但某列的实际误差大小还取决于
   权重比与边缘相位。在抽样格列上核增益恰为 1，该列局部误差为 0，会把误差掩码"刺穿"
   成多段；不同相位/内容下被刺穿的列不同，所以肉眼可见的连续色边宽度在变化，而外廓
   宽度 `r+2s` 是其不变上确界。
2. **前滤波（盒式平均，宽 `r`）不改变结论。** 前滤波只改变样本携带的值，不改变样本
   位置与核支撑，污染带外廓仍是 `B`。实验中两种前端给出相同的 `r+2s`。

### 1.3 测量协议（图像侧，可复算）

- **影响带宽度 `W_inf`（定理对象）**：标记所有"收到对侧侧翼样本非零权重"的细像素列，
  即并集 `B`，量其跨度。子像素跨度严格等于 `r+2s`；开区间内整数列数与跨度相差 ≤1 px。
- **可见宽度 `W_vis`**：对误差 ESF 取 `|ĉ−c|>ε`（ε=边缘幅度的 2%）的连续列，桥接内
  部单位增益刺穿列后量宽。它不超过影响带，且随相位/内容变化。

验证脚本 `measure.py` 在 `r∈{2,3,4}`、`s>r` 的 12 组参数上，影响带跨度与 `r+2s` 完全
相等，整数列计数差恒为 0 或 1 px；2D 实验 9 个单元格的实测-预测差全部为 0 px。

## 2. 收窄核压窄色边，但损失亮度细节：权衡界

### 2.1 色边随核线性收窄

由定理 `W_max(s) = r + 2s`，核半支撑每减小 `Δs`，色边外廓严格减小

```
ΔW = 2Δs,        即   s ↓ ⇒ W ↓，斜率恒为 2（px / 半支撑单位）。
```

### 2.2 亮度重建误差的解析界

把同一条抽样-重建链作用于亮度通道。设亮度信号 `Y` 局部 Lipschitz，常数
`L = RMS|ΔY/Δx|`（在边缘窗口内估计）。重建是相邻样本的归一化凸组合，任意输出位置
`n` 到其参考样本的最远距离为 `s`，故单点误差

```
|Ŷ[n] − Y[n]| ≤ L · s.
```

利用归一化核在抽样格列上增益为 1、最近样本距离为 `r/2`，把参考点取为最近样本，得到
更紧的形式

```
|Ŷ[n] − Y[n]| ≤ L (s − r/2).
```

均方根误差满足同阶上界，并用 `W = r + 2s ⇒ s = (W − r)/2` 换成宽度变量：

```
RMS_Ŷ−Y  ≤  L (s − r/2)  =  (L/4)(W − 2r).
```

**这就是权衡界**：色边宽度 `W` 每减小 1 px，亮度可实现的 RMS 误差上界改变量为

```
系数 = L/4   （亮度单位 / px），
```

即收窄色边的代价是亮度误差预算以 `L/4` 的速率上升；边缘越陡（`L` 越大），代价越高。
`r=2` 时三图的局部 `L_rms` 与逐格界值见结果表，实测 RMSE 全部落在界内（9/9 成立）。

### 2.3 经验系数（给一个数）

在三张图、三个支撑（`s=2.5,3,3.5`，`r=2`）上对 `RMSE_Y = α + βW` 做线性拟合，定义
收窄 1 px 色边的亮度代价 `C = −β`（正值=RMSE 上升量）：

| 图像 | C（亮度 RMSE / 每收窄 1 px 色边） |
|---|---|
| vertical | 0.11 |
| diagonal | 0.30 |
| natural | **1.50** |

取最坏情况给出一个可用的系数：

```
C ≈ 1.50 亮度-RMSE / px（natural，细节最丰富），
```

且 `C ≤ L_rms/4` 的解析界对每一格都成立（natural 的 `L_rms/4≈9.1`，实测 1.50 在界内，
界偏保守但永不被违反）。频域上同步观察到高频能量保留率与梯度能量随 `s` 收窄而下降
（见结果表 `HFret`、`gradL`），与界的方向一致。

## 3. 三组图像的结果（r=2，tent 核）

宽度一律按像素量，并与预测 `r+2s` 比对，判据 `|实测−预测| ≤ 1 px`。

| 图像 | s | 核支撑 2s (px) | 预测 r+2s (px) | 实测影响带 (px) | 差值 | 可见色边列 (2%) | 亮度 RMSE | 高频保留 | 梯度损失 |
|---|---|---|---|---|---|---|---|---|---|
| vertical | 2.5 | 5 | 7 | 7 | 0 | 3 | 1.70 | 0.50 | 0.70 |
| vertical | 3.0 | 6 | 8 | 8 | 0 | 3 | 1.82 | 0.50 | 0.74 |
| vertical | 3.5 | 7 | 9 | 9 | 0 | 5 | 1.92 | 0.50 | 0.80 |
| diagonal | 2.5 | 5 | 7 | 7 | 0 | 18 | 4.77 | 0.48 | 0.74 |
| diagonal | 3.0 | 6 | 8 | 8 | 0 | 18 | 5.03 | 0.48 | 0.77 |
| diagonal | 3.5 | 7 | 9 | 9 | 0 | 19 | 5.38 | 0.47 | 0.82 |
| natural | 2.5 | 5 | 7 | 7 | 0 | 28 | 20.59 | 0.02 | 0.71 |
| natural | 3.0 | 6 | 8 | 8 | 0 | 28 | 21.91 | 0.04 | 0.74 |
| natural | 3.5 | 7 | 9 | 9 | 0 | 28 | 23.58 | 0.03 | 0.85 |

- 9/9 单元格实测宽度与 `r+2s` 差 0 px（全部满足 ≤1 px）。
- 随 `s` 收窄：色边 9→8→7 px；亮度 RMSE 单调上升（natural 23.58→21.91→20.59，反向即
  收窄代价），高频/梯度质量下降。
- 斜边上的色边沿边缘走向逐段变化（相位依赖），但外廓宽度仍为 `r+2s`。
