# 抖动矩阵周期 → 主频 → 可见度：实验报告

## 0. 结论速览

- **命题一（等式）**：对周期为 T 的抖动矩阵，纹路主频严格等于周期的倒数
  $$f^* = \frac{1}{T} \quad (\text{cycles/pixel}), \qquad f^* \propto T^{-1}$$
  三档周期（T = 4, 16, 64 px）16× 零填充 FFT 实测，最大相对偏差 **0.0%**。
- **命题二（阈值与观察条件）**：主频换算成视网膜角频率 $f_{ang}=f^*\cdot\mathrm{ppd}(D)$ 后，
  落在视觉敏感带（本实验 CSF 下为 **0.23–20.4 cpd**）内即可见。敏感带对应的阈值周期为
  $$T^*_{lo}(D)=\frac{\mathrm{ppd}(D)}{f_{lo}}=283.4\,D\ \text{px},\qquad
    T^*_{hi}(D)=\frac{\mathrm{ppd}(D)}{f_{hi}}=3.24\,D\ \text{px}$$
  可见窗口 $T^*_{hi}<T<T^*_{lo}$，两条边界都与观察距离 **严格线性**。
- **复现现象**：4 m 处 T=4 的主频 65.9 cpd 冲出高频边界（Δ = **−0.902**，不可见）；
  换成 T=16 后主频降到 16.5 cpd 回到敏感带（Δ = **+0.333**，可见）——这就是"换个周期，纹路从看不见变看得见"。

## 1. 实验对象：为什么不用 Bayer 矩阵

预实验（`explore_spectrum.py`）先测了标准 Bayer 有序抖动矩阵：它是**蓝噪声**设计，
全部能量被刻意推到奈奎斯特角点 (0.5, 0.5) cy/px，**主频不随矩阵周期变化**
（T = 4…64 实测主峰恒在 0.707 cy/px 径向频率），无法支撑"周期决定主频"的命题。

因此正式实验改用 **raster-order（行优先扫描序）阈值矩阵**（`explore_spectrum2.py` 验证）：
阈值随行号线性增长，对均匀灰阶抖动后产生周期恰好为 T 的水平条带，
其二维傅里叶级数的基频严格位于 1/T，谐波位于 3/T、5/T……主峰始终在基频。
这使"周期 → 主频 → 可见度"的因果链可以被定量检验。

矩阵构造（`dither_core.raster_matrix`）：

```
M[i,j] = i*T + j,  i,j ∈ [0,T)      阈值 = (M + 0.5) / T²
```

50% 灰阶输入下输出 50% 占空比方波条带，画幅 N = 1024。

## 2. 命题一证明：矩阵周期决定主频，主频与周期成反比

### 2.1 解析侧

周期 T 的图案满足 $I(i+T,j)=I(i,j)$，其离散时间傅里叶级数只在
$f = k/T\ (k\in\mathbb{Z})$ 处有谱线。基频（最低非零频率、也是幅度谱主峰）为

$$\boxed{\,f^* = \frac{1}{T}\,}\qquad\Longrightarrow\qquad f^*\cdot T = 1\ \text{（常数，反比关系）}$$

### 2.2 测量侧（图 `figures/fig1_spectrum.png`）

对每档周期做 1024 点 FFT 得到径向幅度谱（图 a，主峰随 T 增大而左移），
再用 **16× 零填充 FFT** 做亚 bin 精度测频（条纹只沿行方向变化，列平均剖面的 1D FFT 与 2D FFT 等价）：

| T (px) | 1/T (cy/px) | 实测 f* (cy/px) | 相对偏差 |
|---:|---:|---:|---:|
| 4  | 0.250000 | 0.250000 | 0.00% |
| 16 | 0.062500 | 0.062500 | 0.00% |
| 64 | 0.015625 | 0.015625 | 0.00% |

图 (b) 中三个实测点全部落在 f* = 1/T 对角线上。等式成立。

## 3. 命题二证明：周期小于阈值时纹路进入视觉敏感带

### 3.1 观察条件如何把图平面频率变成角频率

像素节距 p（本实验取 0.265 mm，约 96 dpi 桌面屏），观察距离 D：

$$\mathrm{ppd}(D)=\frac{D\tan 1^\circ}{p}
=\frac{0.017455}{0.265\times10^{-3}}\,D=65.87\,D\ \text{px/°}$$

主频在视网膜上的角频率：

$$f_{ang}=f^*\cdot\mathrm{ppd}(D)=\frac{\mathrm{ppd}(D)}{T}$$

同一张图，距离拉远 10 倍，角频率升高 10 倍——这是距离能改变可见性的根源。

### 3.2 眼睛光学与 CSF

- **光学 MTF**：3 mm 瞳孔、λ = 550 nm 的衍射受限孔径
  $M(f)=\frac{2}{\pi}\big[\arccos v-v\sqrt{1-v^2}\big]$，
  $v=f/\nu_c$，截止频率 $\nu_c=d/\lambda$ 换算后约 96 cpd。
- **对比敏感度函数**（归一化 Kelly 型，峰值 f₀ = 4.5 cpd，Smax = 150）：
  $$S(f)=S_{\max}\,x\,e^{1-x},\quad x=f/f_0;\qquad C_{thr}(f)=1/S(f)$$
- **敏感带判据**：S(f) ≥ 20（即阈值对比度 ≤ 0.05）。二分求解 S(f)=20 得

$$\boxed{\,f_{lo}=0.232\ \text{cpd},\qquad f_{hi}=20.36\ \text{cpd}\,}$$

### 3.3 阈值周期与观察条件的等式

纹路进入敏感带要求 $f_{lo}\le f_{ang}\le f_{hi}$，代入 $f_{ang}=\mathrm{ppd}/T$：

$$\frac{\mathrm{ppd}(D)}{f_{lo}}\ge T\ge\frac{\mathrm{ppd}(D)}{f_{hi}}
\quad\Longrightarrow\quad
\boxed{\,T^*_{hi}(D)<T<T^*_{lo}(D)\,}$$

| 边界 | 一般式 | 本实验线性式 (px) | D = 0.4 m | D = 4.0 m |
|---|---|---|---:|---:|
| 低频边界 $T^*_{lo}=\mathrm{ppd}/f_{lo}$ | $\dfrac{D\tan1°}{p\,f_{lo}}$ | **283.4 D** | 113.4 px | 1133.6 px |
| 高频边界 $T^*_{hi}=\mathrm{ppd}/f_{hi}$ | $\dfrac{D\tan1°}{p\,f_{hi}}$ | **3.24 D** | 1.29 px | 12.94 px |

**"周期小于某值时落在敏感区"的精确表述**：高频一侧，$T<T^*_{hi}(D)$ 时
$f_{ang}>f_{hi}$，眼睛光学 MTF 已把对比度压到阈值以下，纹路不可见；
$T$ 增大到越过 $T^*_{hi}(D)$ 即进入可见窗口。阈值随距离线性增长，
距离加倍，允许的最小可见周期也加倍（图 `figures/fig3_threshold.png`）。

## 4. 两档距离 × 三档周期：主频与可见度同行（完整数据）

可见度指标定义为**整图对比度**：先把图案过眼睛 MTF 得到视网膜像，
再取全图 RMS 对比度 $V=\sigma(I_{retinal})$（原始二值图 RMS 恒为 0.5，
不经光学衰减无法反映距离效应）。逐档差值写成一个数：

$$\Delta = V-C_{thr}(f^*),\qquad \Delta>0\ \text{可见},\ \Delta\le0\ \text{不可见}$$

| T (px) | f* (cy/px) | D (m) | f_ang (cpd) | 可见度 V（整图 RMS） | 阈值 C_thr | **Δ（一个数）** | 判定 |
|---:|---:|---:|---:|---:|---:|---:|:---:|
| 4  | 0.25000 | 0.4 | 6.59  | 0.4560 | 0.0072 | **+0.4487** | 可见 |
| 4  | 0.25000 | 4.0 | 65.87 | 0.0978 | 1.0000 | **−0.9022** | 不可见 |
| 16 | 0.06250 | 0.4 | 1.65  | 0.4829 | 0.0097 | **+0.4732** | 可见 |
| 16 | 0.06250 | 4.0 | 16.47 | 0.3587 | 0.0260 | **+0.3327** | 可见 |
| 64 | 0.01563 | 0.4 | 0.41  | 0.4942 | 0.0294 | **+0.4648** | 可见 |
| 64 | 0.01563 | 4.0 | 4.12  | 0.4519 | 0.0067 | **+0.4452** | 可见 |

机器可读版：`results/data/measurements.csv` 与 `results/data/results.json`；
同款表格图：`results/figures/fig0_summary_table.png`；柱状比对：`fig4_visibility.png`。

### 逐档与阈值的比对结论

- **D = 0.4 m（近）**：三档主频 0.41–6.59 cpd 全在敏感带内，Δ 分别为
  +0.449 / +0.473 / +0.465，全部可见且余量相近。
- **D = 4.0 m（远）**：
  - T=4：f=65.9 cpd ≫ f_hi=20.4，MTF 把 RMS 从 0.5 压到 0.098，
    阈值已触顶 1.0，**Δ = −0.902**，不可见；
  - T=16：f=16.5 cpd 刚回到敏感带内（距高频边界 20.4 还有 3.9 cpd），
    **Δ = +0.333**，可见但余量是六组中最小；
  - T=64：f=4.1 cpd 接近 CSF 峰值区，**Δ = +0.445**，可见。
- 关键跃迁 **T=4 → T=16（4 m）**：主频反比下降 4 倍（65.9 → 16.5 cpd），
  Δ 从 −0.902 跳到 +0.333，单档差值变化 **1.235**，对应"看不见 → 看得见"。

## 6. 模型参数与适用边界

所有常数集中在 `dither_core.py` 顶部，改参数即可重跑：

| 量 | 取值 | 说明 |
|---|---|---|
| 像素节距 p | 0.265 mm | 96 dpi 桌面屏；手机屏 (~0.12 mm) 会把 ppd 提高约 2.2 倍 |
| 瞳孔 / 波长 | 3 mm / 550 nm | 衍射 MTF；未计入像差与神经采样 |
| CSF | Smax=150, f₀=4.5 cpd | 归一化 Kelly 型；个体差异、亮度适应会平移敏感带 |
| 敏感带判据 | S ≥ 20（C_thr ≤ 0.05） | 工程判据，改动它只移动 f_lo/f_hi 两条边界，不动等式形式 |
| 可见度 | 视网膜像全图 RMS 对比度 | 按要求按整图对比度计算 |

命题一（f* = 1/T）是确定性的傅里叶级数结论，与上述视觉参数无关；
命题二的阈值**数值**依赖 p、D 与 CSF 选择，但
$T^*=\mathrm{ppd}(D)/f_{band}$ 的**函数形式**（与 D 线性、与 p 反比）对任何 CSF 都成立。
