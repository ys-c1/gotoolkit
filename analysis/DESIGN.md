# 误差扩散反馈滤波器设计报告

## 1. 问题与思路

现成 Floyd–Steinberg（FS）误差扩散核的抽头和为 1，在加性量化噪声模型下，
输出误差 `y−x` 相对量化噪声 `q` 的传递函数（噪声传递函数）为

```
NTF(zx,zy) = 1 + H(zx,zy),   H(zx,zy) = Σ_k h_k z_x^(-dx) z_y^(-dy)
```

DC 处 `H(1,1)=Σh=1`，故 **|NTF(0,0)| = 2（+6 dB）**，低频噪声被放大，
表现为平坦区出现明显的低频颗粒/斑块；只调抽头系数无法把这个 DC 增益压下去，
因为 FS 类核必须靠 `Σh=1` 保证零 DC 失真。

改造方法：保留同一个因果 4 抽头支撑，把抽头系数 **按目标噪声谱反解**，
引入全负反馈回路，把低频段的 |NTF| 压下来，同时用全谱能量中性约束保证
总量化误差不升。

## 2. 反馈回路模型

光栅扫描，每个像素：

```
u[n] = x[n] + Σ_k h_k · e[n−d_k]          （误差反馈回路）
y[n] = Q(u[n]),   e[n] = y[n] − u[n]      （均匀量化，levels=32，q=1/31）
```

支撑（阶数说明见 §4）：

| 抽头 | 空间偏移 (dx,dy) | 含义 |
|---|---|---|
| h1 | ( 1, 0) | 右邻 |
| h2 | ( 0, 1) | 正下 |
| h3 | ( 1, 1) | 右下 |
| h4 | (−1, 1) | 左下 |

## 3. 三组目标谱与求解方法

归一化半径 `r = √(ωx²+ωy²)/π`，r=1 对应 Nyquist。三组目标谱共用低频目标
幅度 `a=0.5`（低频功率压到白噪声的 1/4），区别在低频带宽 `r_b`：

```
M(r) = a                       r ≤ r_b        （压制低频，逼近白噪声谱形）
M(r) = 1 + G·s(r)²,  s(r)=((r−r_b)/(1−r_b))²,  r > r_b   （高频补偿抬升）
```

- **为什么低频目标是 0.5 而不是直接取白噪声 1.0**：在 `Σh` 自由的 4 抽头空间里，
  全频带 `|NTF|≡1` 的最小二乘解平凡地塌缩到 `h≡0`（等于不做扩散，实测低频
  占比 0.26，仍偏低频）。把低频目标压到 1 以下、高频允许抬升，才能解出非平凡
  的反馈核；这正是"按白噪声谱整形"——把噪声能量从低频搬到高频，谱形趋于平坦。
- **G 由全谱能量中性闭式解出**：要求 `mean_r M(r)² = 1`，则加性模型下
  理论总误差 `σ_q²·mean|NTF|² = σ_q²`，与直接量化相同（误差不升）。
  记低频网格占比 `f`、`S1=mean(s)`、`S2=mean(s²)`，则
  `G = (−S1 + √(S1² + S2·f·(1−a²))) / S2`。
- **系数求解**：80×80 频率网格上的加权复最小二乘
  `min Σ w(r)·|A(r)h − (M(r)−1)|²`，低频权重 10、高频 1，
  `A(r)` 为支撑对应的复指数矩阵，岭正则 `1e-10`。

三组目标谱参数：

| 目标谱 | r_b | a（低频目标幅度） | G（闭式解） | 低频网格占比 f |
|---|---|---|---|---|
| T1 | 0.15 | 0.5 | 0.01017 | 0.0173 |
| T2 | 0.25 | 0.5 | 0.02917 | 0.0486 |
| T3 | 0.35 | 0.5 | 0.05821 | 0.0955 |

## 4. 反馈滤波器阶数与系数（逐项列出）

**滤波器为 4 阶 FIR（4 个抽头，零记忆深度以外无递归项），与现成 FS 核同支撑，
可直接替换。** 曾试算 8 阶扩展支撑，DC 增益仅再改善 0.05–0.09 而实现成本
翻倍，故不采用。

| 抽头（偏移） | FS 原核（可选） | T1: r_b=0.15 | T2: r_b=0.25 | T3: r_b=0.35 |
|---|---|---|---|---|
| h1 ( 1, 0) 右邻 | +0.437500 | −0.0553615053 | −0.1005258957 | −0.1467598649 |
| h2 ( 0, 1) 正下 | +0.312500 | −0.0545437888 | −0.0917505457 | −0.1167217199 |
| h3 ( 1, 1) 右下 | +0.062500 | −0.0502845583 | −0.0714866399 | −0.0586073817 |
| h4 (−1, 1) 左下 | +0.187500 | −0.0511613437 | −0.0823810890 | −0.0977087826 |
| Σh | +1.0000 | −0.21135 | −0.34614 | −0.41980 |
| \|NTF(0)\|（实测） | 2.0000 | 0.7886 | 0.6539 | 0.5802 |
| mean\|NTF\|²（实测） | 1.3281 | 1.0112 | 1.0304 | 1.0481 |

全部反馈抽头为负；Σh<0 使 DC 增益降到 1 以下。`mean|NTF|²` 略大于 1
（1.01–1.05）是 4 阶自由度对连续目标谱的拟合残差，仿真 MSE 仍低于 FS。

## 6. 三组目标谱的低频占比与量化误差（每组一行）

白噪声理论占比 = r²/4 = **0.0056**。

| 核 | 低频占比（4图均值） | 量化 MSE（4图均值，×1e-3） | 相对 FS 低频占比 | 相对 FS MSE |

## 7. 稳定性与验证

- **误差有界**：所有核（含 FS）在半电平平坦输入、i.i.d. 随机输入、陡渐变上
  实测 `max|e|/q = 0.50`，即量化误差始终不超过半个量化步，无极限环发散。
- **交叉验证**：Go 实现 `internal/dither` 与 Python 仿真在 64×64 参考向量上
  逐点误差 < 1e-12（`go test ./internal/dither`）。
- **回归**：`go vet ./... && go test ./...` 全部通过，原有 codec/api/golden
  测试不受影响。

## 8. 复现方式

```
python3 analysis/design.py     # 目标谱与系数求解（仅依赖 numpy）
python3 analysis/simulate.py   # 扩散仿真与 DFT 低频占比
python3 analysis/evaluate.py   # 生成本报告全部数据 + analysis/report.json
go test ./...                  # Go 实现与 Python 参考交叉验证
```

Go 侧 `internal/dither` 提供 `FloydSteinberg`（原核，可选）与
`FeedbackRB15/25/35` 三个反馈核，通过 `dither.Diffuse(x, w, h, levels, k)` 调用。
