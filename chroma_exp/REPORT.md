# 4:2:0 色度重建相位漂移：线性律、相位估计与误差界

## 0. 结论速览

1. **色度漂移与采样相位偏移量严格成正比**，比例系数就是该通道的局部色度梯度。在受控线性信号上，逐像素回归斜率与相位的比值恒为 `1.0000000`（机器精度），三通道比例系数分别为 R=0.900、G=1.200、B=1.050；换成双三次核，比例系数不变，仅二阶项使整体比值升到约 1.001（偏差 0.1%）。这解释了"换插值核还是偏"——**偏色的一阶来源是采样相位，不是插值核**，核只改变二阶残差。
2. **相位可由相邻块的色度梯度用块内最小二乘估出**：`δ̂ = Σ e·g / Σ g²`（e 为漂移残差，g=gx+gy 为可观梯度）。在物理可实现的平滑相位场上，W4 窗口（块内 4×4 色度点＝全分辨率 8×8）相位 RMSE 低至 **0.003–0.02 像素**。
3. **误差界**给出两层：
   - 结构界（代数恒成立）：`|δ̂−δ| ≤ ‖η‖₂/‖g‖₂`，全部 72 个实验情形均成立，且紧致（最差情形实测 0.4613 vs 界 0.4614）；
   - 曲率界（Taylor 二阶余项）：`|δ̂−δ| ≤ ½δ²·M₂/ḡ_rms`，在曲率主导区成立，在线性信号上正确退化为 0。
4. **窗口权衡**：W4（8×8）在**所有**情形都不劣于 W8（16×16）；在每块独立（iid）相位这种块间不连续的压力测试下，W8 因跨块平均把不一致的相位混在一起，RMSE 从 ~0.04 恶化到 ~0.26。
5. 闭环验证：用估出的相位反向修正，平滑相位场下逐通道残余色差 RMS 降低 **3–15 倍**。

## 1. 模型与坐标约定

全分辨率边长 `N=128`；4:2:0 色度网格边长 64；块边长 8 全分辨率像素（含 4×4 个色度点），全图 16×16=256 块。所有计算 float64、不做 8bit 量化，以隔离"采样相位"这一单一误差源。

- 全分辨率像素 `p` 的中心在物理坐标 `x = p+0.5`。
- 零相位时色度点 `g` 位于 `x_g = 2g+1`，取两侧 2×2 像素的面积均值（box 核）。
- 块 b 施加标量相位 `δ_b`（全分辨率像素单位，x、y 两轴同幅），采样中心移到 `x = 2g+1+δ_b`。box 面积核在相邻整数像素上等价为双线性权重，保证**平移等变**。

关键的物理事实（实验中被直接验证）：

> 带相位的降采样把该块内容平移 `+δ_b`；重建端在**名义网格**上放大、并不知道 δ，于是净漂移被保留。这正是"重建后整体偏色"的来源。

重建核 `k ∈ {bilinear, bicubic(Catmull-Rom)}`。参考信号取"零相位降采样＋同核名义放大"，与重建同核，从而误差只含相位项，不含核的零相位失真（已单独验证零相位内部误差为机器精度 1e-14）。

## 2. 漂移与相位成正比（第一命题）及比例系数

### 2.1 推导

设通道 c 的连续信号为 `f_c`，沿 (1,1) 方向位移 δ。一阶 Taylor 展开：

```
f_c(x+δ, y+δ) = f_c(x,y) + δ·(∂x f_c + ∂y f_c) + O(δ²)
```

故相对名义网格的漂移残差

```
e_c(p) = rec_c(p) − f_c(p) = δ_b · g_c(p) + ε_c(p),   g_c ≜ ∂x f_c + ∂y f_c
```

其中一阶项 `δ·g` 即**与相位成正比的色度漂移，比例系数为该通道的合并梯度 g_c**；`ε` 是 Taylor 二阶及以上余项（含核的有限带宽与块边界效应）。

块 b 内平均：

```
r_c,b ≜ mean_p e_c(p) = δ_b · mean_p g_c(p) + mean_p ε_c(p)
```

### 2.2 实验验证（表 1）

对每通道施加全场统一相位 `δ ∈ {−0.5, −0.25, +0.25, +0.5}`，在内部区域 `[4:−4]`（避开钳制边界）做**逐像素**最小二乘 `e 对 g` 回归，斜率 s(δ) 应等于 δ。同时把内部平均漂移对 δ 线性拟合得 k，与平均梯度 g 比较。

> 为什么换核还是偏：bilinear 与 bicubic 的比例系数 g 完全相同，`k/g≈1.001` 也几乎相同。核只进入二阶项 ε，改变不了一阶的 `δ·g`。因此**只要采样相位存在，换插值核无法消除一阶偏色**，必须校正相位。

## 3. 从相邻块色度梯度估计相位（第二命题）

### 3.1 估计器

在以目标块为中心、含 win×win 块的全分辨率像素集合 Ω 上，仅用**可观测量**——名义重建图自身的梯度 `ĝ`（中心差分）与残差 e——做单回归量最小二乘：

```
δ̂_b = argmin_d Σ_{p∈Ω} (e_p − d·ĝ_p)² = Σ_{p∈Ω} e_p ĝ_p / Σ_{p∈Ω} ĝ_p²
```

- **W4 窗口**：win=1，Ω 为块内 4×4 色度点对应的全分辨率 **8×8** 像素（64 个方程）。
- **W8 窗口**：win=2，Ω 为 2×2 块对应的全分辨率 **16×16** 像素（256 个方程）。
- 可辨识性：当窗口梯度能量 `Σĝ² < τ(=1e-2)` 时判为平坦块，输出 NaN。平坦块无论 δ 多大都不产生可观测漂移，本质不可辨识。

估计在块内做、窗口大小显式如上。

### 3.2 相位场

- `smooth`：块网格白噪声经 σ=2.5 块的高斯低通、缩放到 ±0.5，模拟物理上缓慢漂移的采样相位失配。
- `iid`：每块独立均匀分布于 ±0.5，含块边界不连续，作压力测试。

## 4. 估计误差界

### 4.1 结构界（恒成立）

把模型写成 `e = δ g + η`，η 是除一阶线性项外的全部失配（曲率、核离散化、块边界泄漏、边界钳制）。最小二乘估计量 `δ̂ = gᵀe/gᵀg`，则

```
δ̂ − δ = gᵀη / gᵀg
|δ̂ − δ| = |gᵀη| / ‖g‖₂² ≤ ‖g‖₂·‖η‖₂ / ‖g‖₂² = ‖η‖₂ / ‖g‖₂
```

这是 Cauchy–Schwarz 给出的**代数恒成立**上界，不依赖任何信号光滑性假设。部署时 η 不可直接得，需用核的逼近阶（bilinear 二阶、bicubic 三阶）结合曲率上界估计 `‖η‖₂`；在本受控实验中用真值 δ 计算 η 以验证该界的机制与紧致性。

### 4.2 曲率界（Taylor 余项）

记沿 (1,1) 方向二阶导 `D = f_xx + 2 f_xy + f_yy`，窗内 `M₂ = max|D|`、`ḡ_rms = √(Σg²/N)`。由 `|η_p| ≤ ½δ² M₂`：

```
|δ̂−δ| ≤ ½ δ² M₂ · Σ|g|/Σg² ≤ ½ δ² M₂ / ḡ_rms
```

该界在线性信号上 M₂=0 而正确退化为 0（此时残差只剩块边界/核离散项，由结构界覆盖）；在曲率主导的 B/C 组内部块，曲率界与实测同量级。

### 4.3 实测对照

仅对**内部块** `[1:−1,1:−1]` 检验（图像最外圈块受边缘钳制支配，不属于 Taylor/平移模型，需单独处理）。

| 图像/核/场/窗 | 通道 | 内部实测最大误差 | 结构界 | 曲率界 | 结构界成立 |
|---|---|---|---|---|---|
| A_linear/bilin/smooth/W4 | R | 0.0033 | 0.0178 | 0.0000 | 是 |
| B_smooth/bilin/smooth/W4 | R | 0.0092 | 0.0188 | 0.0667 | 是 |
| B_smooth/bilin/smooth/W4 | G | 0.0081 | 0.0173 | 0.0276 | 是 |
| C_natural/bicub/iid/W4 | R | 0.1082 | 0.2215 | 0.0863 | 是 |
| C_natural/bicub/iid/W4 | G | 0.4070 | 0.4338 | 0.5381 | 是 |
| C_natural/bicub/iid/W4 | B | 0.4613 | 0.4614 | 0.5692 | 是 |

**结构界在全部 72 个（3 图 × 2 核 × 2 场 × 2 窗 × 3 通道）情形无一违反**，最差情形紧致度 0.4613/0.4614≈0.9998。两界互补：曲率界解释光滑信号的主体误差，结构界兜底所有非 Taylor 来源（尤其线性信号与块边界）。

## 8. 适用边界（诚实声明）

- 本实验为隔离相位误差，未做 8bit 量化、未含传感器噪声；加入噪声后估计器方差上升，结构界中 `‖η‖` 需加入噪声项，W8 的降噪收益可能重新显现，需另行标定。
- 图像最外圈块的边缘钳制不在 Taylor/平移模型内，误差界只对内部块声明；工程上应对边界块单独处理（镜像填充或跳过校正）。
- 平坦块（梯度能量低于阈值）相位不可辨识，C 组约 1/3 块如此；这类块本身不产生一阶偏色，可不校正。
- 估计器假设块内为单一标量相位、x/y 同幅；若实际两轴相位独立，需把回归量扩成 (gx, gy) 两参数形式。
