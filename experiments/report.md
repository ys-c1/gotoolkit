# 误差反馈白化量化噪声：系数推导与实测

## 1. 问题定位：为什么加了抖动还"看着像脏"

测试图为 256×256 缓变灰度图（对角斜坡叠加慢变正弦），量化到 16 级（Δ=16）。
残差按行做 FFT，行平均功率谱的**前 1/8 正频频带**（归一化频率 f ∈ (0, 1/16]）
能量占比作为"脏不脏"的指标；白噪声在该频带的理论占比为 1/8 = **12.5%**。

先导实验（`experiments/pilot.py`）：

| 量化配置 | 低频占比 | MSE |
|---|---:|---:|
| 无抖动，四舍五入 | 71.6% | 21.3 |
| 无抖动，截断 | 71.9% | 85.6 |
| **满幅 RPDF 抖动（±Δ/2）** | 12.5% | 42.4（≈Δ²/6） |
| **不足幅 RPDF 抖动（±Δ/8，即 0.25Δ）** | **53.8%** | 22.6 |
| Bayer 4×4 有序抖动 | 2.5% | 42.4 |

结论：满幅 RPDF 抖动本身给出白谱；当抖动幅度不足（或量化器截断、信号过缓）时，
残差与信号相关，谱呈红色，低频占比远超 12.5%，肉眼就是一片片脏斑。
下文以 0.25Δ 不足幅抖动为问题场景（基线实测低频占比 53.8%）。

## 2. 误差反馈闭环与传递函数

行方向一维处理，每行开始反馈状态复位为 0。记号：

- `x[n]` 输入像素，`d[n]` RPDF 抖动，`Q(·)` 步长 Δ 的饱和量化器；
- `u[n]` 量化器输入，`y[n]` 量化输出，`e[n] = y[n] − u[n]` 量化器误差；
- β 为反馈系数，采用"减去历史误差"的约定。

时域闭环：

```
u[n] = x[n] + d[n] − β·e[n−1]
y[n] = Q(u[n])
e[n] = y[n] − u[n]
```

把量化器建模为加性噪声源 e（经典线性化模型），输出端总噪声

```
n[n] = y[n] − x[n] = d[n] + e[n] − β·e[n−1]
```

z 变换（D(z) 为抖动注入，E(z) 为量化噪声）：

```
N(z) = D(z) + (1 − β·z⁻¹)·E(z)
                  └────┬────┘
              噪声传递函数 NTF(z)
```

频域幅度平方（z = e^{jω}）：

```
|NTF(e^{jω})|² = 1 + β² − 2β·cos ω
```

性质：ω=0（直流）处为 (1−β)²，ω=π 处为 (1+β)²。β>0 时 NTF 是高通，
天然把量化噪声推离低频——这正是降"脏"的机理。

## 3. 反馈系数 β* 的解出过程（便于复算）

### 3.1 闭式解：AR(1) 极点对消（Yule–Walker 一阶）

对基线（β=0）噪声 n₀[n] 做一阶自回归建模：

```
n₀[n] = ρ·n₀[n−1] + w[n]，  w 白噪
```

其功率谱为

```
S₀(ω) = σw² / |1 − ρ·e^{−jω}|²
```

反馈后噪声谱 S_n(ω) = S₀(ω)·|1 − β·e^{−jω}|²。
**令反馈零点对消 AR 极点**，即 β* = ρ，则 S_n(ω) = σw² 为常数，谱被拉平。

ρ 的估计（Yule–Walker 一阶方程，纯由数据自相关给出，无需迭代）：

```
ρ = R[1] / R[0]，  R[k] = (1/N)·Σₙ n₀[n]·n₀[n−k]
```

实测（32 次随机实现平均，种子 20261125）：

```
R[1]/R[0] = 0.5124   ⇒   β* = 0.5124
```

复算命令：`python3 -I experiments/ef_experiment.py`，结果写入
`artifacts/ef_results.json` 的 `beta_star_yule_walker` 字段。

### 3.2 交叉验证：实测谱上的平坦度优化

不假设 AR(1)，直接在实测基线谱 S_k 上网格搜索使谱变异系数
CV = std(S_n)/mean(S_n) 最小的 β：

```
β_CV = argmin_β  CV{ S_k·(1+β²−2β·cos ωk) } ，  β ∈ [0, 1]
```

实测 β_CV = **0.663**（`beta_grid_cv_check` 字段）。它比闭式解略大，
因为真实基线不是严格一阶 AR（谱中含信号周期性起伏）；闭式解 0.512 是其
零阶近似，二者方向一致、量级相同。注意带自由常数 C 的普通最小二乘
`min_{β,C} Σ(S_n−C)²` 会退化为 β=0——乘性缩放总能被 C 吸收，
所以平坦度必须用 CV/对数谱方差这类**尺度无关**目标。

### 3.3 三档系数（原路径保留为第 0 档）

| 档位 | β | 含义 |
|---|---:|---|
| 原路径 | 0 | 无反馈，NTF=1 |
| 半档 | 0.5β* = 0.256 | 保守白化 |
| 白化解 | β* = 0.512 | 传递函数极点对消闭式解 |
| 参考档 | 1.0 | 经典一阶 ΔΣ，NTF 在 z=1 处有零点、全高通 |

## 4. 实测结果：低频占比与量化误差并列

条件：Δ=16，抖动 ±Δ/8，256×256 缓变图，32 次实现取均值；
低频占比 = 前 1/8 正频频带能量 / 全部正频能量（去直流）。

| 档位 | β | **低频能量占比** | 相对基线 | **量化误差 MSE** | 白噪 MSE 理论值* |
|---|---:|---:|---:|---:|---:|
| 原路径 | 0 | **53.83%** | — | **22.60** | 22.60 |
| 半档 | 0.256 | **21.84%** | −32.0 pt | **26.42** | 24.08 |
| 白化解 | 0.512 | **5.53%** | −48.3 pt | **32.74** | 28.53 |
| 一阶 ΔΣ | 1.000 | **0.74%** | −53.1 pt | **43.86** | 45.19 |

\* 若 e 为白噪，MSE = MSE₀·(1+β²)；实测值略偏离是因为量化器在饱和区
削波、且闭环后 e 的方差随工作点变化。标准差（32 次）均小于 0.3 个百分点。

读数：

1. 低频占比随 β 单调下降，白化解已把 53.8% 压到 5.5%，**低于白噪 12.5%**
   （说明它略微过白化，真实极点比一阶 AR 估计稍大，与 β_CV=0.663 吻合）；
2. 代价是 MSE 上升：反馈把噪声从低频搬到高频，总能量按 (1+β²) 增长；
3. β=1 的 ΔΣ 档低频几乎清空（0.74%），但 MSE 接近翻倍——是否值得取决于
   后续环节（人眼/低通）对高频的抑制能力。

Go CLI 在同参数下独立复现（`--dither-scale 0.25`，见 `artifacts/u_b*.pgm`）：

| β | Go 实测低频占比 | Go 实测 MSE |
|---:|---:|---:|
| 0 | 59.06% | 22.69 |
| 0.256 | 22.36% | 26.74 |
| 0.512 | 6.00% | 33.06 |
| 1.000 | 0.73% | 43.96 |

（与 Python 的差异来自随机源不同；单调性与量级一致。）

谱图见 `artifacts/fig_spectra.png`，指标并列柱状图见 `artifacts/fig_metrics.png`。

## 5. 反馈回路是否引入不稳定

**判断依据一句话：NTF(z)=1−βz⁻¹ 是 FIR（全零点、无分母极点），
只要 |β|≤1，零点就在单位圆内/上，回路 BIBO 稳定，不会自激；三档系数
（0.256、0.512、1.0）全部满足，故均稳定。**

实测探针（`stability_probe` 字段，记录内部量化误差 e 的最大幅值）：

| β | max\|e\|（内部状态） | max\|输出噪声\| | 结论 |
|---:|---:|---:|---|
| 1.0 | 8.0 | 17.7 | 有界，稳定 |
| 1.1 | 10.2 | 18.3 | 仍有界（量化器饱和兜底） |
| 1.25 | 16.4 | 19.5 | 内部状态开始放大 |
| 1.5 | 89.6 | 21.5 | 线性意义上已失稳 |
| 2.0 | 4.6×10⁷⁶ | 128.2 | 内部状态指数发散，仅靠输出饱和限幅 |

补充：β>1 时把量化器当线性增益，等效回路极点 β 落到单位圆外，内部状态
按 βⁿ 发散（β=2 实测到 10⁷⁶ 量级）；实际输出因量化器饱和在 [0,255]
不会溢出数值范围，但这是限幅硬约束而非稳定裕度，工程上不允许。
代码在参数校验处直接拒绝 |β|>1（`ErrBadBeta`）。
