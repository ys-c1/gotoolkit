# 色度半采样重建核的约束最小二乘设计

## 1. 问题与前向模型

对彩色图做 4:2:0 型色度半采样：亮度 Y 全分辨率保留，两个色度面 Cb/Cr 在水平、
竖直各做 2:1 下采样。题目现象是"色度砍半后重建，彩色边缘偏向一侧，只搜相位救不
回来"——纯相位/平移调整无法补偿重建核本身的幅度误差，因此改为**直接设计重建核**。

### 1.1 一维信号模型（两维可分离使用）

设原信号为 x[0..N-1]，盒式（相邻平均）2:1 下采样：

```
d[k] = (x[2k] + x[2k+1]) / 2,        k = 0..K-1, K = N/2
```

重建端先零插值：u[2k]=d[k]，u[2k+1]=0，再用 5 抽头 FIR：

```
x̂[n] = Σ_{m=-2..2} h_m · u[n+m]
```

### 1.2 关键参数化：归一化核 + 零插入增益补偿

零插值使一半样本为零。若直接对 u 施加"系数和为 1"的核，直流增益只有 0.5，恒定
信号会被衰减一半。因此采用**归一化核 c** 与**物理抽头 h=2c** 的双层写法：

- 归一化核 `c = (c₋₂, c₋₁, c₀, c₁, c₂)`，满足题目两条约束：
  - 系数和为一：c₀ + 2c₁ + 2c₂ = 1
  - 关于中心对称：c₋₂ = c₂，c₋₁ = c₁
- 物理 FIR 抽头 h = 2c。其偶位增益 h₀+2h₂ = 2、奇位增益 2h₁ = 2，两个相位的
  直流增益都恰好为 2，补偿零插入损失后直流无失真。

对称约束把 5 个抽头压到 3 个自由参数 `θ = (c₀, c₁, c₂)`，且

```
c₅ = (c₂, c₁, c₀, c₁, c₂)
```

### 1.3 按相位写出的重建式（低速率域，等价于零插值卷积）

```
偶位  x̂[2k]   = 2·(c₂·d[k-1] + c₀·d[k] + c₂·d[k+1])
奇位  x̂[2k+1] = 2·c₁·(d[k] + d[k+1])
```

边界约定 d[-1]=d[0]、d[K]=d[K-1]（复制外推）。最小二乘只在内部位置 k=1..K-2
拟合（每条 256 长信号仅剔除 2 个边界样本），上采样仍用复制外推处理边界。

## 2. 约束最小二乘与正规方程（矩阵形式）

把所有内部位置堆成设计矩阵 Z（每行对应一个 θ），模型为 `x̂ = 2 Z θ`。优化问题：

```
min_θ  ‖2 Z θ − x‖²      s.t.  C θ = 1,   C = [1  2  2]
```

令 `A = ZᵀZ`，`b = ½ Zᵀx`（目标函数整体除以 4 不改变 argmin，仅缩放乘子）。
引入拉格朗日乘子 λ，KKT 条件即**正规方程的矩阵形式**：

```
┌ A   Cᵀ ┐ ┌ θ ┐   ┌ b ┐
│        │ │   │ = │   │
└ C    0 ┘ └ λ ┘   └ 1 ┘
```

这是一个 4×4 对称（不定）线性方程组，直接 `numpy.linalg.solve` 一次解出，无需求
逆。解出 θ 后由对称关系还原 5 抽头向量 c₅。

### 2.1 二维可分离管线的自洽统计

同一个一维核在水平、竖直两级级联使用，两级输入分布不同，正规方程必须按**真实
输入**分别统计：

- 水平维：目标 = 原色度面的行，输入 = 该行下采样 d；
- 竖直维：目标 = 水平重建后的中间信号 mid 的列，输入 = mid 列下采样。

竖直维的中间信号依赖当前核，故以双线性核初始化、迭代重统计直到抽头收敛
（`design_kernel.py:main`，阈值 1e-10，通常 2~3 轮）。

## 3. 双线性对照路径（保留）

双线性（线性插值）在上述参数化下恰好是

```
θ_bi = (1/2, 1/4, 0),  c₅_bi = (0, 1/4, 1/2, 1/4, 0)
```

物理抽头 (0, 1/2, 1, 1/2, 0)。它作为**独立代码路径**保留（`upsample_bilinear`，
不走 FIR），并在 `main` 开头自检：FIR 路径喂入双线性系数时与专用双线性路径逐点
相等（容差 1e-10）。

## 4. 数据（三档，确定性种子，纯 numpy 合成）

`gen_data.py` 每档生成 10 张 256×256 RGB（前 6 训练 / 后 4 测试），按色度带宽递增：

| 档位 | 主导周期（样本） | 内容 |
|---|---|---|
| tier1 | 48~64 | 长周期缓变条纹 + 大尺度凸包，弱相关噪声 |
| tier2 | 16~24 | 中频定向条带 + 少量硬边矩形（典型彩色边缘） |
| tier3 | 7~9 | 近奈奎斯特多向条纹 + 棋盘 |

噪声一律先高斯平滑再叠加（相关噪声）；不使用白噪声——白噪声在 2:1 下采样后不含
可学习相位结构，只会把解拉回双线性。

## 5. 结果

### 5.1 解出的抽头向量（归一化核 c₅，c₋₂…c₂）与 KKT 乘子

| 档位 | c₋₂=c₂ | c₋₁=c₁ | c₀ | λ |
|---|---|---|---|---|
| tier1 | +2.459e-4 | 0.250027 | 0.499455 | 5.18e5 |
| tier2 | −3.114e-4 | 0.250144 | 0.500336 | 3.52e6 |
| tier3 | −8.111e-4 | 0.250796 | 0.500031 | 2.07e7 |

双线性对照恒为 `(0, 0.25, 0.5, 25, 0)`。可见三档解都非常接近双线性，外抽头 c₂
随带宽升高而增大（符号由正转负、量级 1e-4 → 1e-3）。

### 5.2 色差（测试集，RGB 欧氏距离；平均/最大两列，双线性并列）

| 档位 | 方法 | 平均色差 | 最大色差 | 色度面 RMSE 均值 |
|---|---|---|---|---|
| tier1 | 双线性 | 4.6110 | 14.4850 | 2.1107 |
| tier1 | **CLS 核** | **4.6108** | 14.5439 | **2.1107** |
| tier2 | 双线性 | 9.5682 | 47.2108 | 4.5070 |
| tier2 | **CLS 核** | **9.5658** | 47.2273 | **4.5057** |
| tier3 | 双线性 | 36.3848 | 141.3962 | 17.4253 |
| tier3 | **CLS 核** | **36.3687** | **139.8719** | **17.4162** |

- 平均色差三档全部下降，相对增益 tier1/tier2/tier3 = +0.004% / +0.024% / +0.044%；
- 最大色差在最高带宽 tier3 改善（141.40 → 139.87）；
- 训练集同一 A,b 上的最小二乘目标值，CLS 严格不劣于双线性（V3，差值为正）。

## 6. 讨论：为什么全图增益小，但方法本身有效

这是一个**真实且有理论依据**的结果，不是实现缺陷：

1. **盒式下采样的最优逆问题本就近似线性。** 相邻平均下采样在自然信号的二阶局部
   统计（马尔可夫/随机游走类）下，最优线性内插器就是线性插值，因此双线性已经
   站在最优点附近，五抽头外抽头 c₂ 的可改进空间天然很小。

2. **外抽头的价值集中在近奈奎斯特的结构化信号上。** `verify.py` 的频域解析实验
   （单频正弦、多相位聚合）给出逐频 SSE 增益：周期 64→0.5%、16→6.8%、8→20.0%、
   4.1→33.3%。结构越靠近奈奎斯特，c₂ 越非平凡（可达 −0.1 甚至更大），增益越显著。
   全图是宽频混合，这段高增益被大量低频/平滑成分平均摊薄，于是整体只剩 0.0x%。

3. **去均值是陷阱（已证伪并避免）。** 若拟合前对每行去直流，会恢复出看似可观的
   c₂（如 −0.10），但那是因为去掉直流后 c₂ 在内部位置几乎不可辨识、失去二次正则；
   把该核用到含直流（色度中心 128）的真实信号上，SSE 直接恶化约 9.4 倍
   （见 `verify.py` 附表）。因此正规方程**保留直流**，由"和为一"约束精确处理 DC，
   解出的小 c₂ 才是稳健、可泛化的。

结论：约束最小二乘在严格满足两条约束、且训练目标严格不劣的前提下，给出了比双线性
更低的平均色差；其优势随色度带宽升高而变大，在近奈奎斯特结构化边缘上最明显，这与
题目所述"彩色边缘偏一侧"的高发位置一致。双线性路径完整保留，可随时回退对照。

## 7. 复现

```bash
python3 -I gen_data.py data      # 生成三档图（确定性种子）
python3 -I design_kernel.py      # 求解 + 评估，产物在 results/
python3 -I verify.py             # 独立验证 V1~V4，写 results/verification.txt
```

产物：`results/report.json`（全部 A、b、θ、λ、逐图指标）、`results/summary.csv`
（抽头向量 + 平均/最大色差对照）、`results/per_image.csv`、`results/verification.txt`。
