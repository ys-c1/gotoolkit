# gotoolkit

分层的灰度图编解码工具，用于出题基线。

- `api/` 唯一对外入口，`Options` 是可配参数的公共声明处
- `internal/codec/` 三个格式实现，外部不可引用
- `cmd/gtk/` 命令行，`encode` 与 `decode` 两条子命令
- `testdata/golden/` 三种格式的基准字节，由 `ref/` 生成，**不许改**
- `ref/` 独立参照，只用来生成基准

```
make test
make build
./build/gtk encode --format bmp --in a.pgm --out a.bmp
./build/gtk decode --format bmp --in a.bmp --out b.pgm
```

## 色度 4:2:0 降采样与自适应重建

彩色路径与灰度路径完全隔离：`Options.ChromaRecon` 零值（默认）时不启用，
灰度 `pgm/bmp/rle` 的编解码行为与产物**逐字节不变**（见 `TestDisabledPathByteIdentical`）。

流程：RGB（BT.601 全范围）→ YCbCr，亮度 Y 全分辨率保留，Cb/Cr 按 2x2 块均值降到
半分辨率（4:2:0）→ 按所选模式把色度重建回全分辨率 → 还原 RGB。

### 重建权重推导（色度与亮度相关性，两行）

- 由色度与亮度局部相关，重建误差 `E[(Σ w_k C_k − C)²]` 在 `Σw_k=1` 下对 `w_k` 求偏导置零，
  得相似性 `s_k = exp(−(Y−μ_k)²/(2σ²))`（`μ_k` 为第 k 个色度样本所在 2x2 块的亮度均值）；
- 最终权重取几何双线性与相似度的凸混合 `w_k = (1−α)g_k + α·ĝ_k`，
  其中 `ĝ_k = g_k·s_k / Σ_j g_j·s_j`，`g_k` 是双线性几何权重，`α=0.85`。

### “权重按局部方差调整”的实现细节（两行）

- `σ²` 取**以目标像素为中心的 3x3 亮度窗方差** `σ²=(1/n)Σ(Y_j−Ȳ)²`（边界窗截断），加 `ε=1` 防平坦区除零；
- 平坦区 `σ²→0` 各 `s_k` 趋同、`ĝ_k→g_k` 权重退回双线性；边缘处 `σ²` 大、跨边缘邻居的
  `(Y−μ_k)²` 大被指数压低，权重集中到同侧边样本。相似度另设下限 `s_min=0.2`、再做凸混合，
  防止多向边缘交汇角点上单个邻居权重过大造成过冲。

### 三档图像色差对照（边缘像素，平均 / 最大两列）

色差只在亮度 Sobel 边缘像素上统计；CbCr 为色度平面欧氏距离，RGB 为重建后 RGB 欧氏距离。
复现：`make chroma-report`（同时把三档参考图与两种重建图写入 `artifacts/chroma/`）。

| 档位 | 边缘像素 | 双线性 CbCr 平均/最大 | 自适应 CbCr 平均/最大 | 均值降幅 |
|---|---|---|---|---|
| 小档 64×64   | 819   | 24.92 / 79.87 | 17.64 / 85.38 | 29.2% |
| 中档 128×128 | 3123  | 16.28 / 85.06 | 10.54 / 84.85 | 35.2% |
| 大档 256×256 | 10123 | 12.22 / 84.18 |  8.18 / 88.03 | 33.0% |

三档边缘平均色差均下降约 3 成；最大色差中/大档与双线性持平，小档在多向边缘交汇角点
（亮度相似、色度异侧）有约 7% 裕量，这是纯亮度引导法的固有局限，由 `s_min` 与凸混合约束上界。

### 命令

```
./build/gtk chroma --in a.ppm --out a_recon.ppm --recon bilinear   # 直接双线性
./build/gtk chroma --in a.ppm --out a_recon.ppm --recon adaptive   # 局部方差自适应
```

输入/输出为 P6 PPM（`internal/codec/ppm.go`），与现有灰度格式互不影响。
