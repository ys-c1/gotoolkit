# gotoolkit

分层的灰度图编解码工具，用于出题基线。

- `api/` 唯一对外入口，`Options` 是可配参数的公共声明处
- `internal/codec/` 格式实现，外部不可引用
- `cmd/gtk/` 命令行，`encode`、`decode` 与 `seamcheck` 三条子命令
- `testdata/golden/` 三种格式的基准字节，由 `ref/` 生成，**不许改**
- `ref/` 独立参照，只用来生成基准

```
make test
make build
./build/gtk encode --format bmp --in a.pgm --out a.bmp
./build/gtk decode --format bmp --in a.bmp --out b.pgm
```

## blk 块直流压缩与去缝

`blk`（GTR2）把图切成 `--block N` 的块，每块只保留一个量化直流值（uint8）。
流内一个 `predict` 字节在解码时切换两条路径，二者的直流网格逐字节相同：

- 不预测（默认）：块内填该块直流，相邻块直流不同就出现台阶，缝宽随块长线性增大；
- `--predict`：边界节点取相邻块直流的等权预测，相邻块共用同一节点，块内整数双线性
  插值，边界两侧像素是同一个整数表达式，缝严格为零。

预测系数：内部边节点 `n = (dcL + dcR)/2`，两个系数各 `1/2`，和为一；
二维内部角点为四块等权平均，四个 `1/4`，和仍为一。

三步取整（残余缝宽归属）：

1. `blockDC` 块均值四舍五入到 uint8；
2. 节点平均四舍五入到 uint8 —— 唯一可能产生残余的步骤，但节点被相邻块共享，实测残余为零；
   若改成各块独立取整，奇直流差会产生恰好 1 级残余；
3. 块内插值四舍五入 —— 边界像素严格等于节点，该步对缝中性。

```
make seamcheck   # 同一张 64x64 渐变图，块长 4/8/16 实测两条路径缝宽
```
