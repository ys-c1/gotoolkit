# 有序抖动矩阵的低频泄漏分析与改造

## 1. 问题与思路

加抖动后仍有可见的**规则纹路**（Bayer 矩阵的交叉影线/棋盘格）。规则纹来自阈值矩阵
周期平铺产生的强离散频谱峰。本文按矩阵的**傅里叶系数**量化泄漏到低频的能量，据此
改造矩阵使低频泄漏最小，并验证改造后规则纹对比度下降而量化误差不上升。

所有实现与分析都是确定性、可复现的。

## 2. 矩阵尺寸与通用约定

- **尺寸：8×8，共 64 个阈值等级，取值为 0..63 的一个排列。**
- 抖动规则（周期平铺）：对像素灰度 `g`，令 `scaled = g*64/256`，
  当 `scaled > matrix[y mod 8][x mod 8]` 时输出 255，否则输出 0。
- 三种矩阵同尺寸、同等级集合，因此**抖动噪声同为零均值、同方差**，
  这是后文“量化误差不上升”的理论基础（见 §7）。

## 3. 低频泄漏怎么算（取哪几个傅里叶系数）

对 8×8 矩阵 `M` 先去均值，再做**未归一化二维 DFT**（与 `numpy.fft.fft2` 同约定）：

```
F(v,u) = Σ_y Σ_x (M[y,x] - mean) · e^{-i·2π(vy+ux)/8}
```

- 取 **`fftshift` 后以中心 (4,4) 为圆心、半径 r≤2 的系数，共 13 个**；
- 去掉直流（DC，中心那一个），**对剩余 12 个系数的 |F|² 求和**，记为低频泄漏 `E_LF`。

这 12 个频点相对中心的偏移 (du,dv) 是：

```
(0,±1) (±1,0) (0,±2) (±2,0) (±1,±1)
```

另给一个稳健性对照集合：半径 r≤√5（r²≤5），共 20 个非 DC 系数，记 `E_LF'`。
总功率 `E_tot` 用 **Parseval 恒等式** `E_tot = 64·Σ(M-mean)²` 校验，两者必须相等。

## 4. 三种矩阵的构造规则（均可复现）

### M1 `bayer` —— 经典 Bayer（原矩阵，保留为可选）

- 纯确定性，**不用随机数**。
- 种子 `B1 = [[0,2],[3,1]]`，每放大一级
  `B_{k+1} = [[4B, 4B+2],[4B+3, 4B+1]]`，从 2×2 递归到 8×8。

### M2 `void-cluster` —— Ulichney void-and-cluster 蓝噪声矩阵

- 随机种子固定为 **`SeedVAC = 20261125`**（LCG，见下）。
- 高斯核标准差 **σ = 1.5 像素**，8×8 周期边界，中心权重置 0。
- 步骤：
  1. LCG + Fisher–Yates 洗牌，取前 32 格作为初始 1/2 密度二值图案；
  2. **移除阶段**：反复把高斯响应最大的 1（最紧簇）置 0，按移除顺序赋等级 0..31；
  3. **加入阶段**：从初始图案出发，反复在空格中取高斯响应最大者（最大空隙），
     按顺序赋等级 32..63。
- 浮点并列时取行优先最小下标（容差 `tieEps=1e-9`，对齐 numpy `argmax` 语义）。

### M3 `spectral` —— 频谱优化矩阵（改造后，低频泄漏最小）

- 以 M2 为初值，**目标函数就是 §3 的 `E_LF`（12 个低频系数 |F|² 之和）**。
- 逐对交换两个位置的等级：仅当交换后 `E_LF` 严格下降才接受，否则回退。
- 扫描顺序用 LCG（种子 **`SeedSwap = 20261125 XOR 0x9E3779B9`**）Fisher–Yates 洗牌固定；
  最多 **4 轮**，一整轮无改进即提前停止（实测第 2 轮后收敛，共接受 75 次交换）。
- 接受阈值 `swapEps=1e-6`：最小真实改进约 8×10⁻²，跨实现浮点舍入噪声约 10⁻¹³，
  取 1e-6 同时远离两者，保证不同浮点路径决策一致。结果仍是 0..63 的排列。

**随机数生成器（两矩阵共用，跨 Go/Python 一致）：** 线性同余 LCG，
`a=1103515245, c=12345, m=2³¹`，`state = (a·state+c) mod m`，输出 `state/m ∈ [0,1)`。

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| M1 bayer（改造前） | 20242.193 | 20242.193 | 1397760 | 24.731 | 0.3119 | 30.476 | 12441.947 | 97.459 |
| M2 void-cluster | 439165.864 | 576326.955 | 1397760 | 5.756 | 0.2890 | 212.348 | 12436.184 | 97.436 |
| **M3 spectral（改造后）** | **13.699** | 307520.499 | 1397760 | **4.206** | **0.1716** | 59.988 | 12446.846 | 97.478 |

要点：

- **M3 的矩阵低频泄漏比 M1 降低约 1477 倍（20242 → 13.7，占总功率 1.45% → 0.001%）。**
- **规则纹对比度**用两个量刻画：
  - **PAR（峰均比）**：阈值级 1..63 各二值图案频谱的“最大峰/平均功率”，衡量纹路锐度。
    M1=24.7（极尖锐的规则峰）→ M3=4.2，**下降约 83%**。
  - **各向异性**：过中心的轴对齐方向能量占比，衡量交叉影线那种方向性。
    M1=0.312 → M3=0.172，**下降约 45%**。
- M2 的矩阵值表面 E_LF 很高，但它优化的是**每一级二值图案**的蓝噪声特性（PAR 仅 5.76），
  与 M3 代表两种不同构造哲学；M3 直接以矩阵低频泄漏为目标，所以在该指标上最优。

## 7. 为什么量化误差不上升

三种矩阵都是 0..63 的排列。对任意灰度 `g`，一个 8×8 平铺周期内恰有
`k = round(g·64/256)` 个阈值被越过、输出白点，与矩阵的等级排列方式无关。
因此：

- 二值化噪声 **零均值**（周期内白点数精确匹配目标灰度）；
- 噪声的**方差只取决于等级集合，不取决于排列**——三矩阵等级集合相同，故方差相同。

实测在 7 个均匀灰场（无内容偏置）上，三矩阵 MSE **严格相等 = 12192.500000**
（测试 `TestFlatFieldMSEEqual` 守护）。在含渐变/正弦结构的完整图集上，
M3 与 M1 的 MSE 差异 < 0.1%，仅是特定图像内容下的采样波动，非系统性上升。

## 9. 复现方式

```bash
# Go 权威实现：矩阵、指标、对比图
go test ./...                                  # 全部测试（含与参考值比对）
go build -o build/gtk ./cmd/gtk
./build/gtk dither-report                      # 三矩阵低频能量与误差并列
./build/gtk encode --format pgm --in in.pgm --out out.pgm --dither spectral

# numpy 独立原型（验证算法与频谱量级，与 Go 对照）
python3 -I analysis/dither_prototype.py
python3 -I analysis/make_test_pgm.py artifacts/dither/input.pgm 256
python3 -I analysis/render_compare.py
```

代码位置：

- `internal/dither/`：矩阵构造、DFT 指标、抖动、测试图集与报告（Go 权威实现）；
- `internal/dither/testdata/reference_values.json`：参考指标（由 Go 实现导出）；
- `api/api.go`：`Dither` / `DitherMatrix` 与 `Options.Dither` 公共入口；
- `cmd/gtk/main.go`：`--dither` 标志与 `dither-report` 子命令；
- `analysis/`：numpy 原型、测试图与对比图渲染脚本。
