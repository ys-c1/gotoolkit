# 调色板索引重排与游程最小化

灰度图的像素值可看作调色板索引（256 级灰度 = 256 个索引）。索引序列本身
每项只占 1 字节、体积不大，但它的**顺序**决定下游 RLE 流水线的游程数。
本文把"重排索引使游程数最少"形式化为排序问题，证明它等价于图着色问题，
由着色下界反解理论最优值，给出精确算法与近似算法的误差界，并说明
可逆实现（GTR2）如何保证解码逐像素一致。

## 1. 问题形式化：最小游程排序

设索引序列 $s = s_1 s_2 \dots s_n$，$s_i \in \Sigma$，$|\Sigma| = U = 256$。
游程数

$$R(s) = 1 + \#\{i : s_i \neq s_{i+1}\}.$$

重排是位置置换 $\pi$，得到 $s^\pi_j = s_{\pi(j)}$。重排不改变多重集：
每个值 $v$ 的出现次数 $f_v$ 固定。

> **MINRUN 问题**：给定多重集 $\{f_v\}_{v\in\Sigma}$，求排列使 $R$ 最小。

## 2. 等价于图上的着色问题

取路径图 $P_n$（顶点 $1..n$，边 $(i,i{+}1)$）。称着色 $c: V(P_n)\to\Sigma$
**可行**，当且仅当每种颜色使用次数恰为 $|c^{-1}(v)| = f_v$（指定色类大小）。
着色代价 = **双色边数** $\#\{ij\in E : c(i)\neq c(j)\}$。

**定理 1（等价性）** MINRUN 与"$P_n$ 上指定色类大小、最小化双色边数的
可行着色"互为同一问题：排列 $\sigma$ 与可行着色 $c_\sigma(i)=\sigma_i$
一一对应，且

$$R(\sigma) = 1 + (\text{双色边数}).$$

**证明** 双射由定义直接给出；游程边界 $i$（$\sigma_i\neq\sigma_{i+1}$）
与双色边 $(i,i{+}1)$ 一一对应，故游程数 = 1 + 双色边数。∎

## 3. 着色下界 → 理论最优值

**引理（着色下界）** 任何使用 $k$ 种颜色（$k=\#\{v:f_v>0\}$）的可行着色，
双色边数 $\ge k-1$。

**证明** 把单色极大连通块称为块。每种颜色至少占一个块，故块数 $C\ge k$。
路径图上块数与双色边数满足 $C = 1 + (\text{双色边数})$，于是双色边数
$= C-1 \ge k-1$。∎

**定理 2（理论最优值）** 由定理 1 与引理，$R \ge k$；而按值排序（每种颜色
的顶点排成连续一段）恰有 $C=k$ 个块，达到 $R = k$。故

$$R^* = k = \text{不同索引个数},$$

即着色下界是紧的，理论最优游程数由它直接反解得到。

**备注（为什么还需要近似算法）** 把宿主图从路径换成一般图 $G$（例如二维
网格，游程按行优先之外的邻接计），"每色一块"要求每个色类导出连通子图，
判定其可行性是 NP-难的（与指定大小的连通着色 / convex recoloring 同类）。
路径图上虽然精确算法是线性的，但在**内存受限 / 流式**场景（不能同时持有
整个多重集）下仍需近似算法，见第 5 节。

## 4. 精确算法与复杂度

**算法** 计数排序重排：统计直方图 $f_v$，按值递增依次输出各值的位置
（稳定），得到重排序列与位置置换。

- 时间 $\Theta(n + U)$，空间 $\Theta(n + U)$；$U=256$ 为常数，即线性。
- 游程数达到 $R^* = k$（定理 2），误差为 0。

## 5. 近似算法与误差界

**场景** 流式 / 内存受限：只能缓冲 $W$ 个元素。

**分窗贪心** 把序列切成 $\lceil n/W\rceil$ 个连续窗口，窗内计数排序，
跨窗合并相邻同值段。

**定理 3（误差界）** 分窗贪心的游程数

$$R_{\text{greedy}} \le \lceil n/W \rceil \cdot k = \lceil n/W \rceil \cdot R^*,$$

即它是 $\lceil n/W \rceil$-近似，相对误差 $\le \lceil n/W \rceil - 1$；
$W \ge n$ 时退化为精确算法。

**证明** 每个窗口内不同值至多 $k$ 个，故每窗贡献至多 $k$ 个游程；
共 $\lceil n/W\rceil$ 个窗口，跨窗合并只减不增。∎

- 时间 $O\big(n + \tfrac{n}{W}\cdot U\big)$，额外空间 $O(W + U)$。

## 6. 可逆性：GTR2 格式与逐像素一致

重排本身丢弃位置信息，要解码一致必须保存置换。利用稳定排序的结构：
**同值段内位置严格递增**，故置换可按段差分（段首存绝对位置，段内存
$\text{perm}[j]-\text{perm}[j{-}1] \ge 1$），以 LEB128 变长编码。

```
GTR2 = "GTR2" + u16 w + u16 h + (计数,值) 游程对 + 置换差分变长流
```

解码：先解游程得重排序列 $s'$（游程对累计到 $n$ 为止），再按同一差分
规则重建置换（段边界由 $s'$ 的相邻相等性判定，无需额外标记），校验
perm 是 $[0,n)$ 的置换后执行 $\text{pix}[\text{perm}[j]] = s'_j$。
由于 perm 覆盖每个位置恰好一次且 $s'_j = \text{pix}[\text{perm}[j]]$，
解码结果与原图**逐像素相同**（构造性正确性，由 `TestRLE2RoundTrip`、
`TestReorderRoundTrip` 及三张图的解码对照共同验证）。

体积说明：GTR2 = 8 字节头 + $2\cdot\lceil$游程对$\rceil$ + 置换流
（约 $n$ 个 1–2 字节变长整数）。游程数大幅下降不保证总体积下降——
置换流是还原逐像素顺序的代价；当 $n$ 大、$k$ 小且下游按游程计费时
重排净收益为正（见报告 noisy 行），块少而规整的图则可能变宽（blocks 行）。

## 7. 复杂度汇总

| 算法 | 时间 | 空间 | 游程数保证 |
|---|---|---|---|
| 计数排序精确重排 | $\Theta(n+U)$ | $\Theta(n+U)$ | $R = R^* = k$ |
| 分窗贪心（窗口 $W$） | $O(n+\frac{n}{W}U)$ | $O(W+U)$ | $R \le \lceil n/W\rceil R^*$ |
| GTR2 编码 / 解码 | $\Theta(n)$ | $\Theta(n)$ | 解码逐像素一致 |
