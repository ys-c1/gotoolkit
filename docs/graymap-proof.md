# 灰度映射倒挂问题：证明、修复与复核

位深 b ∈ {8, 10, 12}，码值总数 n = 2^b，取值域 {0,…,L−1}，L = n。
理想连续曲线为

  f(i) = (L−1) · (i/(n−1))^γ，γ = 2.2，i = 0,…,n−1。

f 在 [0,n−1] 上连续、严格递增，且 f(0)=0、f(n−1)=L−1（外层端点）。

**量化模型。** 逐点取整统一写成 q(i) = ⌊ f(i) + r_i ⌋，其中 r_i ∈ [0,1) 是
每个点独立的量化阈值偏移：

- 固定四舍五入对应 r_i ≡ 1/2；
- 本实现的确定性 Bayer 有序抖动对应 r_i = 1/2 + e_i（e_i ∈ [−0.5, 0.4375)），
  仍是 [0,1) 内的逐点偏移；
- 定点实现中各点独立的取整误差同样落在这个模型内。

由 floor 的定义，q(i) ∈ (f(i)−1, f(i)+1)，即逐点总量化误差严格小于 1 LSB。

## 1. 取整为何让单调映射产生倒挂

**定义。** 倒挂指相邻整数映射值严格下降：q(i) < q(i−1)。

**定理 1（倒挂的充要条件）。** 在逐点阈值偏移 r_i 相互独立、可在 [0,1) 内
自由取值的前提下，相邻位置 i−1 → i 可能出现倒挂，当且仅当理想相邻差

  Δ_i = f(i) − f(i−1) < 1。

**证明（必要性，倒挂 ⇒ Δ_i < 1）。** 设 Δ_i ≥ 1。则

  f(i) + r_i ≥ f(i−1) + 1 + r_i > f(i−1) + r_{i−1}，

  其中用了 1 + r_i ≥ 1 > r_{i−1}。实数 x_i = f(i)+r_i 严格大于
  x_{i−1} = f(i−1)+r_{i−1}，故 ⌊x_i⌋ ≥ ⌊x_{i−1}⌋，即 q(i) ≥ q(i−1)，
  不可能倒挂。因此倒挂只可能发生在 Δ_i < 1 的位置。该结论对任意逐点偏移都
  成立，不依赖误差的具体分布。□

**证明（充分性，Δ_i < 1 ⇒ 存在偏移使倒挂发生）。** 因区间
(f(i−1), f(i)) 长度小于 1，其中至多含一个整数边界，且必存在整数 k 使
f(i−1) < k 且 f(i) < k+1（取 k=⌈f(i−1)⌉，边界情形取 k=f(i−1)+1）。
取 r_{i−1} 充分接近 1 使 ⌊f(i−1)+r_{i−1}⌋ ≥ k，取 r_i 充分接近 0 使
⌊f(i)+r_i⌋ ≤ k−1（Δ_i<1 保证 f(i) 未越过 k）。两点偏移独立、符号可相反，
于是 q(i) ≤ k−1 < k ≤ q(i−1)，倒挂发生。固定偏移（如统一四舍五入）只取了
其中一组 r_i，Δ_i<1 的位置是否实际触发取决于该组偏移；本实验用确定性抖动
遍历偏移序列，三档位深均在这些位置实测到倒挂。□

**几何解释。** f 在暗部斜率最小：f′(t) = (L−1)γt^(γ−1)/(n−1)，t→0 时
f′→0（γ>1）。暗部大量相邻位置的 Δ_i < 1（本实验 8/10/12 位分别有
132/530/2123 个这样的位置），逐点独立取整在这些位置无法保证整数差非负，
倒挂集中出现在暗部，表现为"暗部反而更暗"。Δ_i ≥ 1 的位置由必要性证明
保证永不倒挂。

## 2. 累积最大值为何能消除倒挂且不动端点

**定义。** 累积最大值映射 m(i) = max{ q(0), …, q(i) }。

**定理 2（消除倒挂）。** m 非递减，即 m(i) ≥ m(i−1) 对所有 i 成立。

**证明。** m(i) = max(m(i−1), q(i)) ≥ m(i−1)，逐项即得。所有
q(i) < q(i−1) 的倒挂点被之前的峰值填平，倒挂点数为零。□

**定理 3（端点不变）。** 若 q(0) 未被钳位改动且 q(n−1) 是全表最大值，则
m(0)=q(0)、m(n−1)=q(n−1)，外层端点保持不变。

**证明。** m(0)=q(0) 由定义直接成立。又因 f 严格递增、f(n−1)=L−1 为取值域
上界，q(n−1)=L−1 不小于任何 q(j)，故
m(n−1)=max_j q(j)=q(n−1)。本实现中 q(0)=0、q(n−1)=L−1，两个端点在 cummax
前后逐点相等。□

**误差界（相对原始映射）。** 对任意 i，m(i) ≥ q(i)（只抬不降），且
m(i) 等于某个 q(j)（j≤i，峰值一定在原表中出现过）。对任意 j≤i，由 f 单调
与 r_j ∈ [0,1)：

  q(j) = ⌊f(j)+r_j⌋ ≤ ⌊f(i)+r_j⌋ ≤ ⌊f(i)⌋+1 ≤ q(i)+1，

最后一步用 q(i)=⌊f(i)+r_i⌋ ≥ ⌊f(i)⌋（r_i ≥ 0）。故

  **0 ≤ m(i) − q(i) ≤ 1（LSB），整数取值，实测三档最大值均恰为 1。**

**误差界（相对理想曲线）。** 由 q(i)=⌊f(i)+r_i⌋ 有 f(i)−1 < q(i) ≤ f(i)，
结合 m(i) ≤ q(i)+1 与 m(i) ≥ q(i)：

  f(i) − 1 < m(i) ≤ f(i) + 1，即 **|m(i) − f(i)| ≤ 1 LSB**。

实测 max_i|m(i)−f(i)| 为 0.978/0.957/0.999（8/10/12 位），均贴着 1 LSB
的上界但不越界。后续平台铺开只在这个 1 LSB 邻域内重排码级，12 位最终映射
相对原始的 2 LSB 偏差即来自该重排，而非 cummax 步骤。

## 3. 平台段如何处理：避免并列值

cummax 把倒挂点抬到历史峰值后会产生**平台段**（连续相等的 m 值）。平台不
违反单调性（非递减），但并列码值浪费了输出位深。处理规则（实现见
`internal/graymap/graymap.go` 的 `spreadPlateaus`）：

对平台 [s,e]，平台值 v，右邻码级 h（末段平台 h = L−1）：

- 非末段：可用步进空间 span = h − 1 − v，**预留一个码级给右邻**，保证铺开
  后的末点严格小于右邻，不会与右邻重新并列；
- 末段：span = (L−1) − v，允许用到满幅端点；
- 需要的严格步数 need = e − s。
  - **span ≥ need（有富余码级）**：按 v + ⌊k·span/need⌋（k=0,…,need）做
    整除插值，段内每步至少 +1，严格递增、不撞右邻，并列消除；
  - **span < need（位深不足）**：没有足够码级铺给每个输入位置，平台原样
    保留并在报告中标记 `Spread=false`。这是位深的物理限制而非缺陷——它只
    产生非递减的平台，绝不产生倒挂；保留的并列数计入
    `ResidualTieRuns/ResidualTieSteps`，数量可核对。

末段平台铺开后强制把末点钉回 h = L−1，配合定理 3，最终映射的外层端点仍为
(0, L−1)。
