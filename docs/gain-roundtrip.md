# Gain 往返变换的恒等条件与量化误差界

本仓库没有色彩空间转换；唯一的正反变换对是 `Options.Gain`：Encode 施加 `+g`，Decode 施加逆变换。
症状"来回转一趟值对不上"的主因是**公式错**（旧 Decode 用 `(100−g)/100` 做逆，不是正变换的代数逆），
取整（截断而非四舍五入）只贡献 ≤1 LSB 的次要偏置。修复见 `api/api.go` 的 `gainFwd`/`gainInv`。

## 1. 不带量化时恒等成立的代数条件（三行）

设正变换 `y = a·x + c`、逆变换 `x̂ = b·y + d`，像素域 `[0, M]`，`M = 2^n − 1`（n 为位深）。
去掉量化、且钳制不触发时，`x̂ ≡ x` 对所有 x 成立的充要条件：

| 行 | 条件 | 含义 |
|----|------|------|
| 1 | `a·b = 1` 且 `a > 0` | 斜率互为倒数且不退化 |
| 2 | `b·c + d = 0` | 偏移互相抵消 |
| 3 | `0 ≤ a·x + c ≤ M` 对全域 x 成立 | 钳制不触发（无饱和信息丢失） |

逐系数上下界（本仓库 `a = (100+g)/100`，`c = d = 0`，`g ∈ [−100, 100]`）：

| 系数 | 下界 | 上界 | 说明 |
|------|------|------|------|
| a | 0（不含，a=0 即 g=−100 时全域压平、不可逆） | 1（全域恒等）；放宽到 2 时恒等域缩为 `x ≤ ⌊M/a⌋` | `a = (100+g)/100` |
| b | 1（对应 a=1） | +∞（a→0⁺，实际受 g>−100 限制为 b<100…即 g→−100 时 b→100） | `b = 1/a = 100/(100+g)` |
| c | 0 | `M·(1−a)`（a≤1 时保证行 3） | 本仓库 c=0，满足 |
| d | `−M·(1−a)/a` | 0 | 本仓库 d=0，满足 `d = −c/a` |

行 3 的推论：**g > 0（提亮）在全域上不可能恒等**——`x > ⌊M·100/(100+g)⌋` 的像素饱和，
信息已丢失，任何逆变换都救不回；只有 g ≤ 0（压暗）才可能全域恒等。

旧代码的逆是 `b′ = (100−g)/100`，检验行 1：`a·b′ = 1 − g²/10000 ≠ 1`（g≠0）——
**无量化时就已经不恒等**，这就是公式错的判据。

## 2. 带量化后的误差界及其与位深的关系

记 `Q` 为四舍五入，`|Q(t) − t| ≤ 1/2`。往返为 `x̂ = Q(b·Q(a·x))`。
令 `e1 = Q(a·x) − a·x`（`|e1| ≤ 1/2`），由行 1（`a·b = 1`）：

```
x̂ = Q(b·(a·x + e1)) = Q(x + b·e1)
|Δ| = |x̂ − x| ≤ b·|e1| + 1/2 ≤ (b+1)/2   （单位：LSB）
```

Δ 是整数，故 **|Δ| ≤ ⌊(b+1)/2⌋ LSB**，`b = 100/(100+g)`。

与位深的关系（解出来的闭式）：

- 绝对界 `C = (b+1)/2` LSB **与位深 n 无关**；
- 相对满量程 `ε(n) = (b+1) / (2·(2^n − 1)) ≈ (b+1)·2^(−n−1)`，**每加一位约减半**：
  `ε(n+1)/ε(n) = (2^n−1)/(2^{n+1}−1) ≈ 1/2`。

| g | b | 界（LSB） | ε(8) =(b+1)/510 | ε(10) =(b+1)/2046 | ε(12) =(b+1)/8190 |
|---|---|-----------|------------------|--------------------|--------------------|
| +20 | 5/6 | 0（精确可逆） | 0 | 0 | 0 |
| −50 | 2 | 1 | 2.94e-3 | 7.33e-4 | 1.83e-4 |
| −90 | 10 | 5 | 1.08e-2 | 2.69e-3 | 6.72e-4 |

推论：**g ≥ 0 时 b ≤ 1，界 < 1 LSB，而 Δ 是整数，故 Δ ≡ 0**——不饱和区域内往返精确。
误差只来自压暗方向（g < 0），且随 |g| 增大。

## 4. 备注

- 编解码栈本身是 8 位（PGM maxval=255、BMP 24 位）；10/12 位是在变换层用同一组整数公式
  （`gainFwd`/`gainInv` 的 `max` 参数化）验证的，将来支持 16 位 PGM 时公式直接复用。
- `Gain = −100` 时正变换斜率为 0、不可逆，`Decode` 现在返回 `ErrBadOption` 而不是静默给出错误值。
- 若"色彩空间"指的是另一处代码（如 RGB↔YCbCr），本仓库不存在该代码，需要把对应文件指出来再按同一框架分析。
