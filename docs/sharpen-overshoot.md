# 锐化反解：过冲为零下的最大增益与核宽

## 模型与闭式解

```
L  = G_k * I              归一化高斯，σ=(k-1)/3，k 为奇数
H  = I - L                高通，DC 为 0
I' = I + g * H            反锐化掩模
over(x) = max(0, I'(x)-255) + max(0, -I'(x))   过冲（越界部分）
```

逐像素精确反解（本仓库实际使用的公式）：

```
g* = min_x { (255-v_x)/h_x  若 h_x>0 ;
             v_x/(-h_x)     若 h_x<0 },   h = I - G_k*I
```

阶跃边缘（对比度 C=hi-lo，平台 headroom H=min(255-hi, lo)）上：

```
D_k        = (1 - w_c(k)) / 2      w_c 为核中心权重
g_max(C,k) = H / (C * D_k)         C 即阶跃边缘对比度
边缘增幅   = g * C * D_k = H       过冲为零时取到上界 H
```

即 `g_max ∝ 1/(C·D_k)`：增益随核宽 k 增大（D_k 增大）而减小，随对比度 C
增大而减小。过冲为零时，无论取哪个 (C,k)，边缘增幅都被锁在 headroom H。
soft 边缘的逐像素解高于该式，因为 4 像素过渡把边缘高通的峰值削低了。
核宽的选择由平台纹理决定：纹理幅度与对比度成正比，对比度越高纹理的高频
约束越紧，需要更宽的核把它压低，才能取到完整的 H（见末节实测表）。

## 结论

- 解出增益随核宽增大、随对比度增大而减小；关系式 `g_max(C,k)=H/(C·D_k)`。
- 解出增益下实测过冲为 0 像素、0 灰阶：约束成立。
- 1.25× 增益下过冲像素数与过冲量均为正，标为超限。
- 「实际核长」等于「解出 k」：使用的就是反解出的核宽。
- 未锐化（`--sharpen` 缺省）时产物与输入逐字节一致。
