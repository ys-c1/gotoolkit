# 任意步长序列 → 单调重建电平：两步构造、最小二乘最优性与三档实测

量化表要求重建电平单调；按样本“凑”出来的表经常相邻交叉，解码器按码字查表时
`Q(x)=r_{c(x)}` 会随输入 `x` 增大而回落（暗输入反而被重建得更亮）。本文处理：

1. 对**任意给定的正步长序列**给出必然单调的重建电平构造，构造只有两步；
2. 证明该构造是加权最小二乘最优解，最优性条件写成**互补松弛**形式；
3. 三档步长（等宽 8 / 几何 16 / 感知 32）各一组确定性数据，把全部电平、
   误差与误差预测摆开，并列出中点重建误差作参照；
4. 单调性一律**全量逐对比较，不抽样**（电平表枚举 `L(L−1)/2` 对，
   整条 256 点映射枚举 `256·255/2=32640` 对）。

所有数字由 `go run ./cmd/levelreport` 实算，`go test ./...` 逐项锁定；
机器可读结果见 `artifacts/monolevel/report.json` 与 `summary.csv`。

## 1. 记号与问题

8 位灰度定义域 `V={0,…,255}`。给定**步长序列** `Δ_0,…,Δ_{L−1}∈ℤ_{>0}` 且
`Σ_k Δ_k=256`，它铺出严格递增边界

```
t_0=0,  t_{k+1}=t_k+Δ_k,  t_L=256
```

第 `k` 个码字对应整数区间 `I_k={t_k,…,t_{k+1}−1}`（长度 `Δ_k`），
码字映射 `c(x)=k ⇔ x∈I_k` 天然单调不减。每格再给一个**任给的**名义电平
`a_k∈ℝ`（条件均值、目测值、外部凑表值都行，**不要求单调**）与正权重 `w_k>0`
（实现取该格样本占比）。要求解

```
r* = argmin_{r∈ℝ^L} J(r)=Σ_k w_k(r_k−a_k)²
     s.t. r_0 ≤ r_1 ≤ … ≤ r_{L−1}.        (1)
```

可行域是单调锥（闭凸多面体）。目标严格凸（`w_k>0`），故最优解存在且唯一。

## 2. 两步构造（两步各一行）与单调性证明

> **第一步 · 铺边界备名义值**：由步长铺 `t_0=0, t_{k+1}=t_k+Δ_k, t_L=256`，按 `I_k=[t_k,t_{k+1})` 统计（或任取）名义电平 `a_k` 与正权重 `w_k`。
>
> **第二步 · PAVA 保序合并**：从左到右把每格压成一块，只要相邻左块加权均值 `α` 大于右块加权均值 `β` 就合并为加权均值 `γ=(W_Aα+W_Bβ)/(W_A+W_B)` 的一块，反复到没有逆序，展开各块常数即得 `r`。

实现：`internal/monolevel/monolevel.go` 的 `Partition`（第一步）与 `PAVA`（第二步）；
`RoundLevels` 最后做非降的四舍五入与 `[0,255]` 夹紧。

**只有步长、没有任何数据时的显式取法**：第一步直接令 `a_k=m_k=round((t_k+t_{k+1}−1)/2)`
（区间整数点的中点）、`w_k=1`；因步长为正，格心严格递增（见 §3.1），第二步不发生
任何合并、原样返回 `m`。所以“对任意给定步长序列构造单调电平”甚至不需要样本；
而当凑表值 `a` 任意非单调时，第二步保证把它修成单调且 LS 最优（定理 2）。

**定理 1（任意步长序列都构造得出单调电平）**　对任意和为 256 的正整数步长序列、
任意实名义表 `a` 与正权重 `w`，两步构造输出 `r_0≤…≤r_{L−1}`，从而
`Q(x)=r_{c(x)}` 在 `V` 上非降。

**证明**　第一步中 `Δ_k>0`，故 `t_{k+1}>t_k`，边界严格递增、`c` 单调不减。
第二步考察栈：每压入一个单格块后，只要栈顶两块的均值 `α>β` 就把它们合并成
均值 `γ=(W_Aα+W_Bβ)/(W_A+W_B)` 的一块，显然 `β<γ<α`。一次合并后，新块与其
右侧无关（被并的右块本就是栈顶，新块仍是栈顶）；唯一可能新出现的逆序是新块
与其左邻——这正是内层循环下一次检查的对象，会继续合并直到左邻均值不超过 `γ`。
每次合并使块数减一，故过程终止；内层循环退出时栈顶两块已有序，而其下各相邻对
在压栈前就有序且未被改动。对“压入一格 → 内层合并到不能并”逐格归纳，全部格
压完后栈中块均值严格递增，块内取同一常数，展开的 `r` 因而非降。取整映射
`x↦clamp(round x,0,255)` 本身非降，故整数电平也非降。∎

> 只查相邻对在数学上等价于查全部对子（非降有传递性；任一 `i<j` 逆序则沿
> `i→j` 必有相邻逆序）。但本仓库**两种全量检查都做**：`AllPairs` 枚举全部
> `L(L−1)/2` 个电平对，`RampAllPairs` 展开成 256 点后枚举全部 32640 对，
> 覆盖同码字内点与跨码字点，不是抽样。

## 3. 最小二乘最优性与互补松弛条件

给约束 `g_k(r)=r_k−r_{k+1}≤0`（`k=0,…,L−2`）配乘子 `λ_k≥0`，
拉格朗日函数 `𝓛=J(r)+Σ_k λ_k(r_k−r_{k+1})`。KKT 条件为

```
稳定性（驻点）:  2 w_k(r_k−a_k) + λ_k − λ_{k−1} = 0,   λ_{−1}=λ_{L−1}=0
原始可行:        r_k − r_{k+1} ≤ 0
对偶可行:        λ_k ≥ 0
互补松弛:        λ_k · (r_k − r_{k+1}) = 0             ← 最优性条件的互补松弛形式
```

等价的逐约束析取形式更直白：

```
对每个 k： λ_k ≥ 0， r_k ≤ r_{k+1}， 且  λ_k>0 ⇒ r_k=r_{k+1}； r_k<r_{k+1} ⇒ λ_k=0。
```

稳定性递推给出乘子闭式（实现为 `Duals`）：

```
λ_k = 2 Σ_{i=0}^{k} w_i(a_i−r_i),     k=0,…,L−2.        (2)
```

**定理 2（PAVA 解 = (1) 的唯一全局最优解）**　PAVA 输出满足上述全部 KKT 条件，
因 `J` 凸、约束为凸多面体，KKT 点即全局最优解；严格凸保证唯一。

**证明（逐条验证 KKT）**

- **原始可行**：定理 1。
- **稳定性**：由 (2)，`λ_k−λ_{k−1}=2w_k(a_k−r_k)`（约定两端 `λ=0`；在末格
  `k=L−1` 用 `λ_{L−1}=2Σ_i w_i(a_i−r_i)=0`，这正是末块加权均值等于块值），
  代回驻点式逐项为零。
- **对偶可行 + 互补松弛**：需要 PAVA 最终块的前缀均值引理。

  **块前缀引理**：每个最终块 `[s,e)`、块值 `v` 满足：块内任一前缀 `[s,k]` 的
  加权均值 `≥v`，任一下标起的后缀均值 `≤v`。

  对合并过程归纳。单格块平凡。设 A（权 `W_A`、均值 `α`）与 B（权 `W_B`、
  均值 `β`）因 `α>β` 合并，新值 `γ=(W_Aα+W_Bβ)/(W_A+W_B)`，于是
  `β<γ<α` 且有关键恒等式 `W_A(α−γ)=W_B(γ−β)`。考虑合并块的一个前缀：
  若全在 A 内，由归纳其均值 `≥α>γ`；若含整个 A 与 B 的前 `t` 权重
  （`0<t≤W_B`），记该 B 前缀均值为 `m≥β`，则前缀均值 `f` 满足

  ```
  f−γ = [W_A(α−γ)+t(m−γ)]/(W_A+t)
      = [(W_B−t)(γ−β)+t(m−β)]/(W_A+t) ≥ 0,
  ```

  用了 `W_A(α−γ)=W_B(γ−β)`、`t≤W_B`、`m≥β`。故所有前缀均值 `≥γ`。
  后缀对称地有：落在 B 内的后缀均值 `≤β<γ`；若后缀含 A 的尾段（权 `u≤W_A`、
  均值 `q≤α`）与整个 B，则后缀均值 `g` 满足

  ```
  γ−g = [u(α−q)+(W_A−u)(α−γ)]/(u+W_B) ≥ 0.
  ```

  引理得证。现在对块 `[s,e)` 内位置 `k<e−1`，更早各块在 (2) 中的累计和为零
  （每块 `Σw(a−v)=0`），故

  ```
  λ_k = 2 Σ_{i=s}^{k} w_i(a_i−v)
      = 2 W_{s..k}( 前缀均值 − v ) ≥ 0.
  ```

  在块边界 `k=e−1` 处前缀即整块，均值就是 `v`，故 `λ_{e−1}=0`。于是：
  块内相邻电平相等（约束起作用），此处 `λ_k≥0`；块边界电平严格上升
  （约束不起作用），此处 `λ_k=0`——两种情形都有
  `λ_k(r_k−r_{k+1})=0`，互补松弛成立。∎

> **可执行旁证**：`TestBlockPrefixMeanDominates` 对 **50 万组**随机 `(a,w)`
> 逐块、逐位置枚举全部前缀/后缀，反例为 0；`TestDualMultipliersNonnegative`
> （5000 组）、`TestKKTComplementarySlackness`（1000 组逐项检查
> `λ>0⇒r_k=r_{k+1}`、`r_k<r_{k+1}⇒λ=0`）、`TestPAVAOptimalityByBruteForce`
> （枚举全部 `2^(L−1)` 种相邻合并划分）共同锁定结论。三档实测 KKT 残差：
> 稳定性 `≤6e−15`、互补松弛 `≤3e−13`、原始违背 `0`。

### 3.1 为什么误差必然不高于中点重建（在 J 意义下）

中点表 `m_k=round((t_k+t_{k+1}−1)/2)` 只依赖边界。未取整的格心
`c_k=(t_k+t_{k+1}−1)/2` 满足 `c_{k+1}−c_k=(Δ_k+Δ_{k+1})/2>0`（`k+1<L`），
而 `round` 非降，故**任意步长序列下 `m` 都单调**（`TestMidpointAlwaysFeasible`
用 2000 组随机正分拆复核）。因此 `m∈C` 是单调锥里一个显式可行点，由定理 2：

```
J(r*) ≤ J(m).
```

取整后的整数修复表在三档数据上同样满足 `J(r_int)<J(m)`（测试
`TestRepairedBeatsMidpointLS` 锁定）。注意 `J` 度量“对名义表 `a` 的加权距离”；
对原始灰度的像素 MSE 是另一个目标，定理不普遍保证，但**三组数据实测全部
`MSE(r_int) ≤ MSE(m)`**（见 §4，测试 `TestRepairedPixelErrorNotAboveMidpoint` 锁定）。

关于取整：`round(r*)` 不破坏单调；它在一般实数权重下并不总等于整数约束最优，
故这里只声称并验证三档上“取整后仍优于中点”。额外地，
`TestRoundedRepairMatchesDiscreteOptimum` 在 400 组随机整数名义值实例上用
`O(L·256)` 动态规划求整数单调锥最优，取整 PAVA 与之逐例相等（这是整数 `a`
情形的性质，不外推到一般实权重）。

## 4. 三组数据：电平、误差与预测全部摆开

**数据集构造（三组同构、确定性、平台无关）**：每档一条 256 桶直方图，总和
`DatasetN=262144`，每个灰度点计数非零。每格把 `78%` 质量用三角权重压在靠侧边的
`m=max(1,⌊Δ/4⌋)` 个整数点上，偶数格靠右、奇数格靠左，其余 `22%` 均匀铺开；
这使条件均值 `μ_k` 逐格左右交替。名义表按

```
a_k = round( μ_k + 0.42·Δ_k·(+1 偶 / −1 奇) )
```

“凑对比度”，相邻格必然交叉。直方图确定性对半切分：`train[x]=⌊h[x]/2⌋`、
`test[x]=h[x]−train[x]`。下面的 `J` 权重与 `μ_k,σ_k²` 用训练半，像素 MSE 在
测试半上实测（同一份完整直方图上预测式与像素 MSE 由恒等式逐位相等，此性质由
`api` 测试按 `1e−8` 容差锁定）。

### 4.2 误差预测式

全方差恒等式给出（实现 `PredictMSE`）：

```
E[(X−r_{c(X)})²] = Σ_k w_k [ σ_k² + (r_k−μ_k)² ].     (3)
```

因此可用训练集的 `μ_k,σ_k²,w_k` **预测**测试集误差。上表最后两列即预测值，
与相邻的实测 MSE 相差 <1%（训练/测试每灰度至多差一个样本），且预测也给出
“修复优于中点”的同一排序（测试 `TestPredictionMatchesTestError` 按 10% 容差锁定，
实测偏差远小于该容差）。

## 5. 单调性检查为什么可信（逐对、不抽样）

- `AllPairs(levels)`：显式双重循环枚举所有 `0≤i<j<L`，返回逆序对清单；
  三档比较规模分别为 28、120、496，测试还断言规模恰为 `L(L−1)/2`。
- `RampAllPairs(steps, levels)`：先用边界把电平展开成 256 长度的 `Q`，
  再枚举全部 `256·255/2=32640` 对；测试断言比较规模就是 32640。
- 定理 1 的通用测试 `TestArbitraryStepsRepairIsMonotone` 随机生成 300 个
  和为 256 的任意正步长分拆 + 任意名义值，检查取整电平与 256 点映射；
  `TestPAVAMonotoneForAnyInput` 对 2000 组、长度至多 40 的任意 `(a,w)`
  逐相邻对检查。没有任何抽样核验被当作全量结论——“随机”只用于扩大输入覆盖，
  每次输入内部仍是逐对/逐位置全检。
