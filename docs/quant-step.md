# 量化步长的体积–误差 Pareto 前沿

量化步长 `s` 要么体积大要么误差大：`s` 越小产物体积 `V` 越大、误差 `D` 越小。
本文用拉格朗日乘子法推出给定体积约束下的最优步长，解出体积–误差 Pareto 前沿，
再用三档目标体积实测验证。实测由 `go test ./api/ -run TestStepFrontier -v` 复现。

## 1. 模型

测试图：256×256 行斜坡（每行像素 0..255），N = 65536 像素，RLE 格式（GTR1，
8 字节头 + 每游程 2 字节）。量化器为中点重建均匀量化：

```
q(v) = min(⌊(v + s/2)/s⌋·s, 255)
```

**体积模型。** 量化后每行的游程数等于不同量化值的个数。斜坡行取值 0..255，
步长 `s`（整除 256）下共 `r(s) = 256/s + 1` 个不同值（`+1` 来自舍入边界的半宽 bin），故

```
V(s) = 8 + 2·256·r(s) = 520 + K/s,   K = 2·256·256 = 131072
```

**误差模型。** 均匀量化、箱内误差近似均匀分布，经典结果

```
D(s) = s²/12            （连续近似）
D(s) = (s²+2)/12        （整数像素离散修正：整箱误差 {−s/2,…,s/2−1} 的均方）
```

## 2. 拉格朗日乘子求解

给定目标体积 `T`，求 `min D(s)` s.t. `V(s) = T`。构造拉格朗日函数（用连续模型）：

```
L(s, λ) = s²/12 + λ·(520 + K/s − T)
```

**第一步，对 s 求偏导并置零：**

```
∂L/∂s = s/6 − λK/s² = 0   ⟹   s³ = 6λK   ⟹   λ(s) = s³/(6K)
```

乘子 λ 的物理意义：体积约束每收紧一字节，最小误差的增长率，即前沿的斜率（差一个符号）。

**第二步，代入约束解出步长。** 由 `V(s) = T` 得 `520 + K/s = T`，故

```
s*(T) = K / (T − 520)
```

**第三步，回代得乘子与前沿。** 把 `s*` 代入 `λ(s)` 与 `D(s)`：

```
λ*(T) = s*³/(6K) = K² / (6·(T−520)³)
D*(T) = s*²/12  = K² / (12·(T−520)²)      （离散修正再 +1/6）
```

`D*(T)` 即体积–误差的 Pareto 前沿：任何步长方案的点 `(V, D)` 都不可能落到前沿左下方；
实测点若明显高于前沿，说明该档步长分配不均（没有取到 `s*`）。

## 3. 三档目标体积的解

取三档目标 `T`（分别约为原始 RLE 体积 131080B 的 1/4、1/8、1/15），
`s* = K/(T−520)` 恰好为整数 4、8、16：

| 档 | 目标 T (B) | 连续解 s* | 取整 s | 乘子 λ* | 前沿 D\*（连续） | 前沿 D\*（离散修正） |
|----|-----------|----------|--------|---------|-----------------|---------------------|
| 大 | 33288 | 4.000 | 4  | 8.1380e-05 | 1.3333 | 1.5000 |
| 中 | 16904 | 8.000 | 8  | 6.5104e-04 | 5.3333 | 5.5000 |
| 小 |  8712 | 16.000 | 16 | 5.2083e-03 | 21.3333 | 21.5000 |

注意 λ\* 每档乘 8：有效体积 `(T−520)` 每减半，边际代价变 8 倍（λ ∝ (T−520)⁻³）。

## 4. 实测对照（解与实测点并列）

实测走完整 `api.Encode`（`Step=s`）→ RLE → `api.Decode` 管线，逐像素算 MSE：

| 档 | 解出 s | 前沿 D\* | 实测 V (B) | 实测 MSE | 实测 PSNR | MSE 偏差 |
|----|--------|---------|-----------|----------|-----------|----------|
| 大 | 4  | 1.5000 | 33288 | 1.4844 | 46.42 dB | −1.0% |
| 中 | 8  | 5.5000 | 16904 | 5.4375 | 40.78 dB | −1.1% |
| 小 | 16 | 21.5000 |  8712 | 21.2500 | 34.86 dB | −1.2% |

三点实测体积与模型逐项一致（体积模型本身就是该图的精确计数）；实测 MSE 略低于
离散修正前沿约 1.1%，来自首尾两个半宽 bin 的误差小于整箱——三点都落在前沿上
（略低不违反前沿：前沿是整箱假设的上界）。`TestStepFrontier` 另扫描 s∈[1,255]
全部整数步长，确认三点均不被任何其它点支配（Pareto 最优），且预算内无误差更小的
步长；若某档实测点高于前沿，即说明该档步长分配不均。

**前沿三点（步长与误差成对）：**

```
s=4   D=1.4844   (V=33288B, 46.42dB)
s=8   D=5.4375   (V=16904B, 40.78dB)
s=16  D=21.2500  (V= 8712B, 34.86dB)
```

## 5. 默认步长产物不变

`Step ≤ 1`（含零值默认）不做量化，三种格式产物与引入该选项前逐字节一致，
由 `TestGoldenBytes`（对照 `testdata/golden/`，不许改）与 `TestStepDefaultUnchanged`
双重保证。`Step` 越界（<0 或 >255）报 `ErrBadOption`。

## 6. 复现

```
go test ./api/ -run TestStepFrontier -v   # 打印上表实测行
./build/gtk encode --format rle --step 8 --in a.pgm --out a.gtr
```
